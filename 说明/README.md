# 算法说明与手册编排

这里保存算法的用途、条件、推导和模块顺序；算法实现仍在01–09章节，验证仍在测试目录。说明按相同章节、文件名对应，例如 `说明/02-数据结构/树状数组.md` 对应 `02-数据结构/树状数组.cpp`。

说明使用普通Markdown。独占一行的 `<!-- code: 模块名 -->` 表示在此插入源码中同名模块，浏览说明时可以点击上文的源码链接。源码以 `// @code 模块名` 分段，标记不进入打印内容。模块只在源码定义一次；生成器按说明引用它们，不在Markdown复制代码。

每个源码模块必须在说明中恰好出现一次；缺漏、重名、未知引用会使生成失败。其余模板也按正文与代码交替排印：顶层模块说明提为正文，操作附近的短注释保留在代码中。

[全局变量说明](全局变量说明.md)覆盖199份模板，包含输入、对象字段、下标、结果位置、修改与重置规则；生成器按源码路径把对应段落放在该模板代码前。缺项、未知项、重名均中止生成，不手动复制说明到tex。

LaTeX是从源码与说明组合出的排版结果，打印配置控制收录和字号，模块顺序由对应说明控制。修改算法或说明后同步现有tex；公开说明应独立完整，不依赖个人阅读记录。

归属规则：整数掩码枚举在第一章，长位向量在数据结构，全部掩码聚合在动态规划；实现与调试章只收性能、随机和交互工具。赛事特殊模型仍留在建模专题，常用结论不重复基础操作与已完整展开的模板。
