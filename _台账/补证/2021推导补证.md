## B. The Matching System：补全提前停止的计费 DP

题面第4–5页，题解第3页。两串都长n≤1000，要求分别输出最大匹配（星号长度从大到小）及最小匹配（从小到大）的最坏成功输入。两种都必须给，**不是在两者之间选择增长慢的那一种**。原页只是比较两类坏构造的增长速度。

计费边界：每枚举一个星号长度消耗1，包括长度0；0/1/^在目标串非空时消耗1，目标已空立即失败不消耗；模式已空仅检查目标是否已空，检查本身不消耗。成功后立即停止，不把成功分支之后的其他尝试计入。

固定任意模式P和目标T，0基索引。令 ok(i,j) 表示 P[i..] 与 T[j..] 是否可匹配，d(i,j) 为从该状态开始直到本次返回或成功的实际能耗。这个状态包含完整后缀，没有其他环境，故同一状态每次被递归访问的成本都相同；用DP只是批量计算它的值，并不假装原匹配器真的做了记忆化。

终止：ok(n,j)=(j=n)，d(n,j)=0。

普通字符：j=n时 ok=false、d=0；否则无论最后是否匹配，先付1。若字符相容（相等或模式为^），继承 ok(i+1,j+1)，d=1+d(i+1,j+1)；若不相容，ok=false、d=1。

星号：枚举结束位置q∈[j,n]，每个尝试付1+d(i+1,q)。最大匹配按q降序、最小匹配按q升序；找到第一个 ok(i+1,q)=true 即停止，全部失败才扫完整个区间。

设上一行 a(q)=1+d(i+1,q)，前缀和 A(t)=Σ_{q<t}a(q)。

- 最大匹配：令 t=max{q:ok(i+1,q)}，没有则t=-1。若t≥j，ok=true、d=A(n+1)-A(t)；否则ok=false、d=A(n+1)-A(j)。
- 最小匹配：令 t=min{q≥j:ok(i+1,q)}，没有则t=n+1。若t≤n，ok=true、d=A(t+1)-A(j)；否则ok=false、d=A(n+1)-A(j)。t由j降序维护最近真位置。

逐行计算O(n²)，只存上/下两行O(n)空间；能耗取模1e9+7，匹配可行性必须单独保存，不能用模后能耗判断分支是否成功。

```cpp
// descending=true 为最大匹配；返回{成功与否,实际能耗mod}。
pair<bool,int> match_cost(string P,string T,bool descending){
    const int mod=1000000007; int n=T.size();
    vector<int> d(n+1); vector<char> ok(n+1); ok[n]=1;
    for(int i=(int)P.size()-1;i>=0;i--){
        vector<int> nd(n+1); vector<char> no(n+1);
        if(P[i]=='*'){
            vector<int> pref(n+2); int top=-1,next=n+1;
            for(int q=0;q<=n;q++){
                pref[q+1]=(pref[q]+(long long)d[q]+1)%mod;
                if(ok[q]) top=q;
            }
            for(int j=n;j>=0;j--){
                if(ok[j]) next=j;
                no[j]=next<=n;
                int l=j,r=n+1;
                if(descending && top>=j) l=top;
                if(!descending && next<=n) r=next+1;
                nd[j]=(pref[r]-pref[l]+mod)%mod;
            }
        }else for(int j=0;j<n;j++){
            nd[j]=1;
            if(P[i]=='^'||P[i]==T[j]){
                no[j]=ok[j+1]; nd[j]=(d[j+1]+1LL)%mod;
            }
        }
        d.swap(nd); ok.swap(no);
    }
    return {bool(ok[0]),d[0]};
}
```

题解给出的坏构造及边界修正：最大匹配 n≥3 时 P=`*`^(n-2)+`0*`，T=`0`+`1`^(n-1)；n=1可用`0`/`0`成本1；**n=2应另用`*0`/`00`成本3**，直接套`0*`/`01`仅成本2。最小匹配可用 s=floor(n/2)+1 个星号，再接n-s个^，目标全0；此式包含n=1的`*`/`0`，成本2。

独立验证：n≤3的全部4^n模式、2^n目标及两种顺序，对照原规则的直接递归，计费DP完全一致；n≤5枚举全部成功输入，修正后的两种构造都达到真最大值。依次最大/最小成本为n=1:(1,2)、n=2:(3,4)、n=3:(8,7)、n=4:(31,10)、n=5:(119,14)。从本文原样提取的C++17实现也已编译，样例、这些边界、不匹配及目标为空检查通过。原题解只给经验构造，没有写一般极值证明；以下另补独立证明，枚举仅作交叉核对。

### 最小匹配：一般极值及构造证明

设模式有r个星号、s=n-r个普通字符（含^）。把模式分成普通字符块及其间的星号游程。一个中间普通块可以取**最早完整匹配的位置**：若原来有一个成功方案把它放在更晚位置，移到更早位置后，后续星号只需吸收多出的间隙，后续各块仍可保持原来的位置，故匹配仍可完成。因此最小匹配一旦完整匹配一个中间块，就不会因为后续失败而退回修改该块的位置。末尾没有星号的最后一块需要贴目标末尾；此前的完整匹配尝试若尚未到末尾仍视作失败，其比较数至多该块长度。

同一游程的若干连续星号中，除最后一个外都取0即可，最后一个能够吸收该游程任意所需长度；故不会回退去重新枚举此前星号。若某游程在成功路径中吞了t个目标字符，最后一个星号恰好尝试0,1,...,t，共t次失败、一次成功。所有游程吞掉的字符总数是n-s=r，所以全部失败尝试次数恰好r。每次失败最多付1次星号枚举及s次普通字符比较；成功路径本身付r+s=n。因此

$$\text{cost}_{\min}\le n+r(s+1)=n+r(n+1-r).$$

构造r个前缀星号接s个^、目标全0，前r-1个星号取0，最后一个星号尝试0..r。每个失败尝试都比较完整s个^才发现目标尚未耗尽，恰好达到上界。对r∈[0,n]最大化二次函数，得

$$\boxed{\max\text{cost}_{\min}=n+\left\lfloor\frac{(n+1)^2}{4}\right\rfloor}.$$

取r=floor(n/2)+1即可，包含n=1和n=2，无额外例外。当s=0时最后一个星号仍要枚举到吞完目标，成本2n，与公式一致。

### 最大匹配：失败树上界与一般极值证明

以下成本先按整数算，不取模。为给任意输入上界，将普通字符都当作^、并令模式耗尽时仍返回失败，使所有分支都走完。设后续失败代价函数为f(t)，t为剩余目标长度，定义两个算子

$$Sf(t)=t+1+\sum_{q=0}^{t}f(q),\qquad Cf(t)=\begin{cases}0&t=0,\\1+f(t-1)&t>0.\end{cases}$$

S表示一个星号枚举全部长度，C表示普通字符。容易直接展开得到 SCf(t)-CSf(t)=t（t>0），t=0时差1。因此把星号移到普通字符之前不减完整失败树代价。两个算子都对非负函数单调。

记F_r(t)=S^r C0(t)，即r个前缀星号加一个必失败普通字符的完整代价。按星号递归深度计数，有

$$F_r(t)=\binom{t+r+1}{r}-1+\binom{t+r-1}{r}\quad(t\ge1).$$

第一项减1是所有星号枚举边数：第h层有C(t+h,h)个分支，h=1..r，用曲棍球杆恒等式求和；第二项是最终目标仍非空时的一次字符比较，等价于r个吞字符数之和≤t-1的弱组合数。F_0(t)=1；F_r(0)=r。

F_r随r严格增加。增量δ_r(t)=F_{r+1}(t)-F_r(t)非负，且δ_{r+1}(t)=Σ_{q≤t}δ_r(q)，故增量亦随r不减。下面证明n≥3时所有成功输入成本都≤F_{n-2}(n)+1。

**末尾有c≥1个星号。** 设总普通字符数s≥1。只要前面的模式成功，末尾c个星号在最大匹配中立即成功，付c。前面模式的完整失败树上界，移动星号到前面后是S^(n-c-s)C^s0(n)。由于C^s0(t)=min(s,t)，且C^s0≤S^(s-1)C0（s=1相等；s≥2时SC0=2t+1≥min(s,t)，以后应用S只增不减），故成本≤F_{n-c-1}(n)+c≤F_{n-2}(n)+1。若整串都是星号，第一星号吞完目标，其余取0，代价仅n。

**末尾为普通字符且s≥3。** 完整失败树上界≤S^(n-s)C^s0(n)。因为C^s0≤S^(s-2)C0（s≥3），上界≤F_{n-2}(n)，甚至严格小于目标上界。

**末尾为普通字符且s=1。** 模式只能是n-1个星号接一个字符。成功要求该字符匹配目标最后一位。若前面有a个星号，最大匹配先吞完目标导致失败，再令后续剩1字符，依次递归，总代价D_a=C(a+2,2)。于是本项成本C(n+1,2)≤F_{n-2}(n)+1；n=3直接核8≥6，n≥4可用F_{n-2}≥F_2=(n+1)(n+2)证明。

**末尾为普通字符且s=2。** 模式写作a个星号、字符X、b个星号、字符Y，a+b=n-2。

1. b=0：最后两字符必须匹配目标末两位。最大匹配在第一次剩余长度2时就成功；此前所有字符叶的剩余长度仅0或1，代价不超过一个普通字符的失败树。成功叶多比较一次，所以成本≤F_a(n)+1。
2. a=0：X在目标第一位固定成功，剩余b个星号及尾Y的成本为C(b+2,2)，总成本1+C(b+2,2)，由上一项的同样界可得≤F_{n-2}(n)+1。
3. a,b≥1：尾Y必须匹配目标最后一位。当X尝试目标最后一位时，后面为空，b个星号会失败，额外付b；当X在更早的某位置成功时，因b≥1，尾Y必能匹配目标最后一位，后缀立即成功，付D_b=C(b+2,2)。其余X失败叶仅付1，与F_a一致。a个星号使X恰落在最后一位的分配数为L=C(n+a-2,a-1)，因此成本≤F_a(n)+bL+C(b+2,2)。

为把第三小项压到所需界，令δ_a=F_{a+1}(n)-F_a(n)。公式给出

$$\delta_a=\binom{n+a+1}{a+1}+\binom{n+a-1}{a+1}.$$

第一项至少3L：在n+a+1个元素中指定3个新元素，恰选其中2个、其余选a-1个，共3L种不同子集。另由增量单调有δ_a≥δ_0=2n，故δ_a≥L+n。于是F_{a+b}-F_a≥bδ_a≥bL+bn，而n=a+b+2保证bn≥C(b+2,2)-1。代回即可得成本≤F_{a+b}(n)+1=F_{n-2}(n)+1。所有模式形态至此均已覆盖。

最后看题解构造：n-2个前缀星号接`0*`，目标`0`+`1`^(n-1)。在最大匹配顺序中，只有所有前缀星号都吞0时字符0才成功，该分配是最后一个；此前所有失败分支完整走过，与F_{n-2}(n)完全一致，最后尾星号再付1。因此达到上界：

$$\boxed{\max\text{cost}_{\max}=\binom{2n-1}{n-2}+\binom{2n-3}{n-2}\quad(n\ge3)}.$$

n=1最大值1；n=2最大值3，用`*0`/`00`达到，不能套上式。至此两种模式均有一般上界及达到上界的构造，证明独立于n≤5的枚举观察。计费DP可继续作为实现核验；也可由闭式组合数直接计算模1e9+7的构造成本。

## G. Cyclic Buffer：补全端点成本与第一不可读值查询

题面第12页，题解第11页。读窗为位置1..k，读出不会删除数，必须依值1..n读取，可双向移动整个环。下面位置统一0基，p_i为值i的原位置。令o为当前读窗的原位置起点，窗是环区间[o,o+k)，原位置p的当前位置为(p-o+n)%n。

可以选最优方案，使每次移动都等到当前所需值无法读取才开始，并在它**第一次进入读窗**时停止。否则把进入后的移动推迟到下一个无法读取的值，继续原路线即可，不增加总移动；路线中多余反向折返也可删去。因此每次真正移动后，当前值必在读窗左端0或右端k-1。

设 f(i,0/1) 为访问i时i在左/右端的最小成本，对应窗起点

$$o_{i,0}=p_i,\qquad o_{i,1}=p_i-k+1\pmod n.$$

从状态(i,b)出发，求

$$j=\min\{x>i:(p_x-o_{i,b}+n)\bmod n\ge k\}.$$

这是**按访问值顺序的第一个窗外值**，不是窗口内未访问值的总数。i+1..j-1无需移动即可连续读；若不存在j，答案候选为f(i,b)。原页 w 若仅定义为“能直接访问的整数数量”，会混淆顺序，不能按所有窗内数的计数直接令j=i+w。

若存在j，令 z=(p_j-o+n)%n，保证k≤z≤n-1：

$$f(j,0)\gets\min(f(j,0),f(i,b)+n-z),$$

$$f(j,1)\gets\min(f(j,1),f(i,b)+z-k+1).$$

前者向右移n-z步，j第一次出现在位置0；后者向左移z-k+1步，j第一次出现在位置k-1。两成本和为n-k+1，不是随意取两端点之间的无向圆距离。所有转移j>i，可按i升序处理。

初始窗o=0、成本0，同样先找第一不可读值j并套上述两式；若所有值都在初始窗内，直接答案0。这涵盖k=n。k=1两个端点重合，允许两个同窗状态取min。答案可能大于32位，f用64位。

O(nlogn)的明确实现无需补猜原页BIT：建立原位置上的区间最小值线段树，叶p_i初值i。按值i升序，将p_i置为∞，表示已处理的值≤i。对每个有限状态查询读窗的补集（长度n-k的环区间，拆至多两个普通区间），区间最小值恰是上述j。查询到∞表示剩余值全在窗内。每个i仅两状态、一次点修改，空间O(n)。这个替代只使用库中现有点改/区间最小值接口，毋须打印一份重复线段树代码。

独立验证：n≤6全部排列、全部k，共5039例。端点跳段DP与另一种保留全部n个旋转状态的逐值DP完全一致；后者独立枚举任意旧/新旋转和圆上最短移动，未复用端点性质。原样例{2,4,3,5,1},k=3得到3。

可迁移短说明：可行位置为连续窗时，移动停止在首次进入端点；先跳过顺序中整段当前可行项，再以第一不可行项做两端DP。环窗的两方向进入成本需按实际有向移动写，不能拿“总可读数”替代连续可读前缀。

## C/I：原页笔误现已配对确认

**C Laser Trap**：题面第6–7页、题解第4页。激光是全部点对之间的有限线段，路线可弯曲，目标远在全部坐标外，原点不在任何点/线段上。原点在剩余点凸包内时，被凸包边界围住，无法逃；在凸包外时，由严格分离存在通向远处的射线，再从远处绕到目标。故要保留最多同一开半平面的点，角宽为π，原图的π/2错误。无原点在线保证不存在反向共线点对，所以开/闭半周边界不会意外把反向端点同时留下；同向点则必须允许同时计入。不是固定朝目标方向的四分之一平面。

**I LCS Spanning Tree**：题面第14页、题解第14–15页。边权为最长公共**子串**，目标明确是**最大生成树**。SAM颜色合并必须按len降序（父链上父len严格更小），让更长共同子串已处理后，再在len(u)层合并尚不同的颜色连通块；每次成功合并贡献len(u)。原页“长度从小到大”与其“孩子已合并”的后续论证冲突，属方向笔误。SA height笛卡尔树也应先处理更高LCP层；无共同字符的剩余连通块在权0层接完，n=1答案0。
