## 对手册的直接启发

从已读内容看，很多题的难点是模型转化、最优解的形态、边界和计数去重。下一轮应优先给已有模板补紧凑的使用说明与例子，再决定是否增加整份代码。

|适合补的短说明|具体阅读例子|放置方向|
|---|---|---|
|先证明最优解可以规范成某种形态|2025 沈阳 B 的纯色层＋画笔层；武汉 I 的单调段|贪心／构造|
|逆序推约束，省去正向决策或二分|2025 成都 C 渡河；沈阳 E 抽牌位置上界|双指针、贪心、概率|
|乘零使非最优历史重新参与最优计数|2025 沈阳 D 七段显示屏|DP 计数边界|
|区间移动只计算左右差集|2025 成都 K 等长区间平移|单调队列应用|
|特殊角色赋不同系数，解线性不变量|2025 沈阳 K 青蛙反射接力|构造／不变量|
|按深度桶＋DFS 序把树上集合化成区间|2025 武汉 B 子树同深度 2-SAT|线段树建图|
|最大匹配覆盖与博弈胜负的关系|2025 武汉 D|匹配与交替路|
|概率转尾和，再转受限排列计数|2025 沈阳 E|概率期望|

|秩一行列式构造|2025 武汉 M|线性代数公式|
|周期与 border 链的等差结构|2025 武汉 J 等字符串题|字符串短说明，先补齐缺失推导|
|唯一规范表示才能哈希判等|2025 CCPC 总决赛 L 的异或空间|线性基|
