# 抓取说明（给批量抓取子代理看）

## 任务
从洛谷题目列表页抓取题目的**难度**和**算法标签**，只保留目标题号（见 `IDs_P.txt`），其余题目全部忽略。

## 工具
只能用 **web_fetch**（shell 命令没有外网）。每次抓一个 URL。

## URL 模板
```
https://www.luogu.com.cn/problem/list?difficulty=<难度值>&page=<页码>&type=P
```
- `difficulty` 用 1~8（1 最简单）。
- `page` 从 1 开始。

## 返回内容的形状
每个题目占两行，例如：

```
-   ### [超级玛丽游戏](/problem/P1000)

    [字符串](/problem/list?tag=2) · [O2优化](/problem/list?tag=108)
```

- 第一行：`### [题目名](/problem/P1000)` → 题号是 `/problem/P1000` 里的 `P1000`。
- 第二行：标签链接列表，标签名就是链接文字（如 `字符串`、`O2优化`），用 ` · ` 分隔。有些题目这一行**没有内容**（那就是没有标签）。
- 标签里会混有年份（如 `2003`）、来源（如 `NOIP 提高组`、`USACO`）、省份（如 `上海`）等非算法标签，**全部照实记录**，后面由主控筛。

## 处理流程
1. 先读 `C:\Users\22974\Desktop\algorithm template\_台账\IDs_P.txt`，把 504 个目标题号装进脑子（它们是 `P1000` 这样的形式）。
2. 对你负责的每个 (难度, 页码) 组合，按上面的 URL 模板抓取。
3. 从返回内容里解析出**所有**形如 `P\d+` 的题号；只保留出现在 `IDs_P.txt` 里的。
4. 把命中的行写入你的分片文件：

```
路径：C:\Users\22974\Desktop\algorithm template\_台账\shard_<分片名>.csv
格式（UTF-8，带表头）：
id,difficulty,tags
P3374,4,树状数组;模板题
P3372,4,线段树;模板题
```

- `id`：题号，如 `P3374`
- `difficulty`：**URL 里用的那个难度数字**（如 `4`），不要写中文难度名
- `tags`：该题全部标签，用**分号**分隔；没有标签就留空
- 每页处理完就**用 write 工具重写整个分片文件**（累积所有已处理的页），避免中途失败白干
- 同一题号若出现在多页，只保留一条
