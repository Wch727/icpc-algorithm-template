## 单调队列.cpp

- **接口**：填 n,k,a[1..n]，调用 solve()；ans[i] 存窗口最小值下标，窗口值为 a[ans[i]]，完整窗口从 i=k 开始。
- **DP**：dp(a,k) 返回 f；a 下标从 1 起，f[0]=0，f[i]=a[i]+前 k 个状态的最大值，k>=1。
- **复杂度/边界**：均 O(n)；窗口版先加入再查询，DP 版先转移再加入；相等值保留最新下标。
- **自定义**：替换队首过期和队尾淘汰条件；候选按入队顺序失效，新候选在旧候选剩余有效期内有效且始终不劣。

## 单调栈.cpp

- **接口**：填 n,a[1..n]；right_greater()/left_less() 写 ans[i]，分别为右侧首个严格更大/左侧最近严格更小的下标，无解 0。
- **贡献**：histogram() 返回非负高度、单位柱宽的最大矩形面积；sum_min() 返回所有非空子数组最小值之和。
- **复杂度/边界**：均 O(n)；弹栈确定右边界，剩余栈顶给出左边界。sum_min 左边界严格小于、右边界小于等于，相同最小值归给最右位置，避免重复。

## 二维差分.cpp

- **接口**：填 n,m,a[1..n][1..m]，build() 建差分；add(x1,y1,x2,y2,v) 对闭矩形加 v；所有修改后 restore() 写回 a。
- **复杂度**：建表/还原 O(nm)，修改 O(1)，静态空间 O(N²)。
- **边界**：预留 0 行/列及 n+1、m+1，要求 n+1、m+1<N；a 第 0 行/列为 0。全零起始可清 d 后直接 add；restore 只调用一次。

## 反悔贪心.cpp

- **接口**：job_schedule(vector<Job>) 求单位耗时任务最大收益，Job 为 {截止时间 d,收益 p}，d、p 非负。
- **接口**：task_schedule(vector<Task>) 求不同耗时任务最多完成件数，Task 为 {耗时 t,截止时间 d}，t>0、d>=0。
- **复杂度/原理**：均 O(n log n)，空间 O(n)；按截止时间排序，前者撤销最低收益，后者替换最长耗时。
- **边界**：从时刻 0 开始，无其他先后或释放时间约束；不同耗时还要求最大收益时，两种策略都不保证最优。

## 分数规划.cpp

- **接口**：填 n,k,a[1..n],b[1..n]，fractional() 返回恰选 k 件时 sum(a)/sum(b) 的最大值；1<=k<=n，b[i]>0。
- **含义/判定**：a 是收益、b 是成本，如总价值/总重量；check(x) 取最大的 k 个 a[i]-x*b[i]，和非负表示有方案达到比值 x。
- **复杂度/边界**：O(100*n log n)，空间 O(n)；总和之比不是各项比值的平均数。其他约束须重写 check 的选取方式。

## 高精度BigInt.cpp

- **接口**：BigInt(ll)/BigInt(string) 构造，支持带符号加减乘除取模及六种比较；to_string() 输出，divmod(a,b) 同时返回商、余数。
- **按区复制**：公共区 0 必留；非负加法 0+1，带符号加减 0+1+2+3，乘 int 0+4，高精乘高精 0+5，除法/取模 0+2+4+6，比较 0+7。
- **复杂度**：L 为较大位数；加减/比较/输出及乘 int 为 O(L)，高精乘除最坏 O(L²)，空间 O(L)。
- **边界**：字符串为合法十进制，可带负号，不识别加号；支持 LLONG_MIN/INT_MIN，零规范为正。除数非零；商向零截断，余数与被除数同号。

## 高维差分.cpp

- **接口**：以三维为例，填 n,m,k,d[1..n][1..m][1..k]，build() 原地建差分；add(x1,y1,z1,x2,y2,z2,v) 对闭长方体加 v；所有修改后 restore()，结果仍在 d[x][y][z]。
- **更高维**：修改 2^D 个角点，每选一个右端点+1 符号翻转；建表沿每维倒序相减，还原沿每维正序累加，其他坐标枚举全部格子。
- **统一递推**：e_i 为第 i 维单位向量。建表 G_0=a，G_i(x)=G_{i-1}(x)-G_{i-1}(x-e_i)，G_D=d；还原 F_0=d，F_i(x)=F_{i-1}(x)+F_i(x-e_i)，F_D=a。边界坐标为 0 时值为 0；原地建表当前维倒序，还原正序。
- **容斥公式**：b 遍历 {0,1}^D，|b| 为置位数；d(x)=Σ_b(-1)^|b|a(x-b)，直接还原 a(x)=d(x)+Σ_{b≠0}(-1)^(|b|+1)a(x-b)。模板末尾同时给出区域修改的角点公式。
- **复杂度/边界**：三维修改 O(1)，建表/还原 O(nmk)，静态空间 O(N³)；D 维建表/还原 O(D*S)，S 为格数。各维从 1 起，第 0 层为零，n+1,m+1,k+1<N；全零起始清 d 后跳过 build，restore 只调用一次。

## 记忆化搜索.cpp

- **接口**：填 n,m,h[1..n][1..m]，solve() 清缓存并返回滑雪最长严格下降路径；dfs(x,y) 返回从该格出发的长度，包含当前格。
- **复杂度/边界**：O(nm)，静态空间 O(N²)，最坏递归深度 O(nm)；严格下降保证无环。答案至少 1，所以缓存 0 表示未计算；其他模型若答案可能为 0/负数，使用独立访问标记。
- **替代**：长链可能爆栈，可按高度从低到高排序后迭代转移；更换输入需清缓存。

## 快读快写.cpp

- **接口**：readd() 返回 ll，print(ll) 输出整数；空格/换行需自行 putchar。
- **调用**：按已知数量读取合法、范围内整数，支持 ll 两端极值；使用 getchar/putchar，不需要刷新自建缓冲。
- **复杂度/边界**：O(读写字节数)，递归输出空间 O(位数)；EOF 返回 0，不能用于区分 EOF 与整数零。

## 离散化.cpp

- **接口**：填 n,a[1..n]，discrete() 排序去重并生成 id[i]；id 从 1 起，排名 r 的原值为 b[r-1]，原数组 a 不变。
- **复杂度/边界**：O(n log n)，空间 O(n)；保留大小关系，不保留实际距离。查去重值中的插入位置直接用 lower_bound。

## 逆序对.cpp

- **接口**：count_inv(l,r) 返回闭区间 a[l..r] 的严格逆序对数，同时把该区间排序；a 为 int 数组。
- **复杂度/边界**：O(n log n)，额外数组 O(n)，递归深度 O(log n)；相等不算逆序，计数用 ll。重复统计须恢复原序列；l>=r 返回 0。

## 三分法.cpp

- **接口**：实现 double f(double)/ll g(ll)；ternary_min(l,r) 搜实数，ternary_int(l,r) 搜整数，均返回最小值位置。
- **适用**：最优区间左侧严格下降、右侧严格上升；单调函数可用，多局部极值或非最优平台不可直接套。
- **复杂度/边界**：实数 100 轮、每轮两次 f；整数 O(log(r-l+1)) 轮后枚举至多 4 点。l<=r，整数 r-l 不溢出；按范围和精度调整实数轮数。
- **最大值**：实数版比较 < 改为 >；整数版比较目标函数的两处 < 改为 >，循环条件不改。

## 双指针.cpp

- **接口**：two_sum(a,target) 在非降序 int 数组中找两个不同位置，返回 0 起下标，无解 {-1,-1}；O(n)，额外空间 O(1)。
- **接口**：min_cover(s,t) 返回覆盖 t 全部字符（含重复次数）的最短子串长度，无解 -1、空 t 返回 0；O(|s|+|t|)，空间 O(256)。
- **边界**：min_cover 按字节计数，返回长度而非位置；窗口类双指针须保证扩张/收缩条件的单调性。

## 位运算技巧.cpp

- **接口**：lowbit/is_pow2/bit_count/bit_length 参数为 ull；set_bits(x) 返回置位编号；submasks(mask) 枚举含 0 的子集；supermasks(mask,bits) 枚举 bits 位内超集。
- **固定大小子集**：next_combination(x) 返回下一更大的同置位数掩码，无下一项返回 0；combinations(bits,k) 枚举恰有 k 位的掩码，0<=k<=bits<=63。
- **SOS/异或**：sos_sum(f,bits) 原地求子集和，f.size()==2^bits，O(bits*2^bits)；加改减为逆变换。xor_prefix(n) 求 0 到 n 的异或，区间用两个前缀异或，左端点为 0 时单独处理。
- **边界**：clz/ctz 不可传 0，超集要求 mask<2^bits；枚举耗时和空间随结果数增长，push_back 可换题目操作。所有 mask 的子集总量为 O(3^bits)。

### 位运算技巧：对齐块异或和

`xor_block_sum(b,len,v)` 返回 unsigned __int128；len=2^k、0<=k<64、b%len=0，区间 [b,b+len) 不得越出 ull 值域。O(1)，支持完整的 64 位 v，128 位输出需自行转十进制。
