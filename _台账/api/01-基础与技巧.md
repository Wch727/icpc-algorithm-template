## 单调队列.cpp

- **功能**：滑动窗口最小值与最大值
- **接口**：
  - `void sliding_window(int k)` — 读取 `n,a[1..n]`，写入 `win_min/win_max[1..n-k+1]`
  - `void init_q()`、`void push_keep_inc(int i)`、`void push_keep_dec(int i)`、`void pop_expire(int i,int k)`；`int q_front()` 返回队首值
- **复杂度**：整体 O(n)，空间 O(n)
- **最小调用示例**：
  ```cpp
  n=3; a[1]=3; a[2]=1; a[3]=2;
  sliding_window(2);
  cout << win_min[1] << " " << win_max[2];
  ```
- **注意**：要求 1<=k<=n；q 存下标，q_front 不检查空队；两种单调方向分开初始化。
- **结论**：可用于窗口最值和有单调候选集合的 DP。

## 单调栈.cpp

- **功能**：求邻近大小元素及向右可见对数
- **接口**：
  - `void get_nge()` / `void get_nge2()` — 右侧首个严格大于 / 大于等于的下标
  - `void get_nse()` / `void get_nle()` — 右侧首个严格小于 / 左侧最近小于等于；`ll count_see()` 返回可见对数
- **复杂度**：每次 O(n)，空间 O(n)
- **最小调用示例**：
  ```cpp
  n=3; a[1]=3; a[2]=1; a[3]=2;
  get_nge(); get_nle();
  cout << nge[2] << " " << count_see();
  ```
- **注意**：a 与结果均为 1..n，无对应位置记 0；相等高度会在 count_see 中弹出，不能混用严格与非严格比较。
- **结论**：可套用最近更大元素、直方图边界和贡献计数。

## 二分答案.cpp

- **功能**：在单调判定区间中搜索边界
- **接口**：
  - `ll bs_first_true(ll l,ll r,F check)` / `ll bs_last_true(ll l,ll r,F check)` — 闭区间首真 / 末真，无解 -1
  - `ll lower_id(ll* p,ll len,ll x)` — p[1..len] 首个 >=x，缺失 len+1；`double bs_double(double l,double r,F check)` 返回 100 次迭代后的右端
- **复杂度**：整数 O(log V) 次判定，浮点 100 次；额外空间 O(1)
- **最小调用示例**：
  ```cpp
  auto check=[](ll x){return x>=7;};
  ll ans=bs_first_true(0,10,check);
  cout << ans;
  ```
- **注意**：首真要求假到真，末真要求真到假；-1 可与合法负答案重合；端点差及 mid±1 仍须避免 ll 溢出。
- **结论**：可求最小可行上界、最大可行下界及有序数组插入位置。

## 反悔贪心.cpp

- **功能**：工作调度、股票收益及反悔启发式
- **接口**：
  - `ll solve_job_schedule(vector<Job> v)` — 单位时长工作收益，Job 含 int d,p；`ll stock_unlimited_best(const vector<ll>& p)` — 无限次交易

- **复杂度**：调度 / 选物 O(n log n)，空间 O(n)；股票无限 O(n)/O(1)，限次 O(nk)/O(k)
- **最小调用示例**：
  ```cpp
  vector<Job> jobs={{1,10},{1,20},{2,5}};
  ```

- **结论**：调度可套用截止时间选任务；限次股票应用 DP，不能泛化成背包最优贪心。

## 分治.cpp

- **功能**：快速幂、归并逆序对和非空最大子段和
- **接口**：
  - `ll qpow(ll a,ll b,ll mod)` / `ll qpow_iter(ll a,ll b,ll mod)` — 模幂
  - `ll merge_sort(int l,int r)` — 排序并返回逆序对；`ll max_sub(int l,int r)` — a[l..r] 非空最大子段和，a 为 ll 数组
- **复杂度**：模幂 O(log b)，递归空间 O(log b) / 迭代 O(1)；数组分治 O(n log n)，归并临时空间 O(n)
- **最小调用示例**：
  ```cpp
  n=3; a[1]=-2; a[2]=5; a[3]=-1;
  cout << max_sub(1,3);
  ll inversions=merge_sort(1,3);
  ```
- **注意**：max_sub 要求非空区间；merge_sort 改写 a；幂要求 b>=0、mod>0，ll 乘法不防溢出。
- **结论**：可迁移到跨中点统计和递归合并；与归并排序文件的同名函数返回类型不同。

## 高精度BigInt.cpp

- **功能**：带符号十进制大整数四则运算、余数与比较
- **接口**：
  - `BigInt()`、`BigInt(ll v)`、`BigInt(const string& s)`；`BigInt operator+(const BigInt&) const` 等 +,-,*,/,%；乘法另有 int 重载
  - `string to_string() const`、`bool is_zero() const`、六种比较返回 bool；`static pair<BigInt,BigInt> divmod(const BigInt& a,const BigInt& b)` 返回商、余数
- **复杂度**：L 位加减 / 比较 / 输出 O(L)，乘除 O(L²)，空间 O(L)
- **最小调用示例**：
  ```cpp
  BigInt x(string("12345678901234567890"));
  BigInt y(7); auto qr=BigInt::divmod(x,y);
  cout << qr.first.to_string() << " " << qr.second.to_string();
  ```
- **注意**：d[0] 为低位；字符串不校验数字、只识别负号；ll/int 最小负数取负溢出；默认零 len=0 与 BigInt(0) 比较不规范；除零返回 {0,a}。
- **结论**：适用于超出 ll 的整数计数与竖式计算；商向零截断、余数与被除数同号。

## 归并排序与逆序对.cpp

- **功能**：稳定排序并统计严格逆序对
- **接口**：
  - `void merge_sort(int l,int r)` — 排序 a[l..r]，向全局 ll inv 累加逆序对
  - `ll count_inv(int l,int r)` — 返回逆序对数，同样把 int a[l..r] 排序
- **复杂度**：O(n log n)，临时数组 O(n)，递归栈 O(log n)
- **最小调用示例**：
  ```cpp
  n=3; a[1]=3; a[2]=1; a[3]=2;
  inv=0; merge_sort(1,n);
  cout << inv;
  ```
- **注意**：闭区间、常用 1..n；调用 merge_sort 前清 inv；count_inv 也改数组，重复统计需恢复原序列，相等不算逆序。
- **结论**：可用于排序、序列逆序统计和合并时的跨区间计数。

## 记忆化搜索.cpp

- **功能**：数字三角形最大路径和与滑雪最长下降路径
- **接口**：
  - `ll dfs_triangle(int i,int j)`、`ll dp_triangle()`、`ll dfs_triangle_code(int i,int j)` — 三角形路径和
  - `int code(int i,int j)` 返回 i*m+j；`int dfs_ski(int x,int y)` 返回严格下降路径长度
- **复杂度**：三角形 O(n²)，滑雪 O(nm)；静态二维及编码缓存 O(N²)，递归栈最坏 O(nm)
- **最小调用示例**：
  ```cpp
  n=2; a[1][1]=1; a[2][1]=2; a[2][2]=3;
  memset(vis,0,sizeof(vis));
  cout << dfs_triangle(1,1);
  ```
- **注意**：三角形 1<=j<=i<=n，滑雪 1..n×1..m；换数据清 vis/bvis/f；编码步长 m 应大于最大 j，且 id<N*N。
- **结论**：适合无环状态依赖、只访问部分状态的 DP；滑雪严格下降保证无环。

## 进制转换.cpp

## 快速排序与快速选择.cpp

- **功能**：原地排序与按位置选第 k 小
- **接口**：
  - `void quick_sort(int l,int r)` — 排序 int a[l..r]
  - `int quick_select(int l,int r,int kth)` — 返回目标位置值；kth 是数组绝对下标，1..n 全区间才等于第 kth 小
- **复杂度**：排序平均 O(n log n)、最坏 O(n²)，栈 O(log n)；选择平均 O(n)、最坏 O(n²)，额外 O(1)

- **结论**：可用于顺序统计、分位数和原地排序。

## 离散化.cpp

- **接口**：

## 三分法.cpp

- **功能**：单谷求最小值、单峰求最大值的位置
- **接口**：
  - `double trisearch_min(double l,double r,F f,int iter=200)` / `double trisearch_max(double l,double r,F f,int iter=200)` — 返回位置
  - `double f_val(int i,double x)` 计算第 i 个二次函数；`double F_val(double x)` 返回 n 个函数的最大值，系数下标 0..n-1
- **复杂度**：三分 O(iter*C_f)，额外 O(1)；F_val 单次 O(n)
- **最小调用示例**：
  ```cpp
  auto f=[](double x){return (x-2)*(x-2);};
  double x=trisearch_min(0,5,f);
  cout << x << " " << f(x);
  ```
- **注意**：返回的是极值位置，需再调用 f；F_val 要 n>=1；文件末尾悬空 template<typename F> 使整文件无法直接编译，摘取完整函数使用。
- **结论**：可处理凸函数最小化及二次函数上包络最小值。

## 位运算技巧.cpp

- **功能**：最低位、位数、树状数组跳转及子集枚举
- **接口**：
  - `int lowbit(int x)`、`bool is_pow2(int x)`、`int bit_count(int x)`、`int bit_count_ll(ll x)`、`int bit_length(ll x)`

- **复杂度**：基础计数 O(位数)；单 mask 枚举 O(2^popcount(mask))；按位数排序 O(bits*2^bits)，结果空间 O(2^bits)

- **结论**：用于状态压缩、子集 DP 和树状数组。

## STL容器速查.cpp
