## NTT.cpp

- **功能**：模 998244353 的精确多项式卷积
- **接口**：`void ntt(ll a[],int n,int inv)` 原地变换，0 正、1 逆；`void poly_mul(ll a[],int n,ll b[],int m,ll c[],int &clen)` 输出卷积并设 clen=n+m-1
- **复杂度**：变换长度 L，时间 O(L log L)，空间 O(L)，静态缓冲 N=2^19
- **最小调用示例**：
  ```cpp
  ll a[2]={1,2},b[2]={3,4},c[3];
  int len; poly_mul(a,2,b,2,c,len);
  ll ans=c[2];
  ```
- **注意**：输入 0..n-1/0..m-1、输出 0..clen-1，系数 [0,mod)；n,m>=1；poly_mul 的 L<=2^19，直接 ntt 需正的 2 次幂且 L 整除 mod-1。
- **结论**：模卷积、生成函数乘法与组合计数。
