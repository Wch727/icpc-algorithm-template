## 向量基础.cpp

- **功能**：二维向量运算、线段关系、距离与点在多边形内判定
- **接口**：
  - `Point(double x,double y)` 及 +、-、*；`int sgn(double x)` 返回 -1/0/1；`double dot(Point a,Point b)`、`cross`、`len(Point a)`、`len2(Point a)`；`bool is_parallel(Point a,Point b)`、`is_vertical` 判平行/垂直
  - `bool on_segment(Point a,Point b,Point p)`、`bool segment_cross(Point a,Point b,Point c,Point d)` 含端点；`Point line_intersect(Point a,Point b,Point c,Point d,bool &ok)` 求直线交点；`double point_seg_dis(Point a,Point b,Point p)` 求距离
  - `int point_in_polygon(vector<Point> &p,Point q)` 返回 0 外部/1 边界/2 内部；`bool in_convex_polygon(vector<Point> &p,Point q)` 接收逆时针凸多边形，含边界；顶点 0..n-1，无重复首点
- **复杂度**：基础运算与线段接口 O(1)，两种多边形判定 O(n)；额外空间 O(1)
- **最小调用示例**：
  ```cpp
  vector<Point> p={{0,0},{2,0},{0,2}};
  int where=point_in_polygon(p,Point(0.5,0.5));
  bool hit=segment_cross({0,0},{2,2},{0,2},{2,0});
  ```
- **注意**：EPS=1e-9；line_intersect 的实际计算沿 ab 使用 s1/(s1-s2)，一般不是真交点，且 ok=false 时返回未初始化 Point；凸内测需非退化多边形，空集会返回 true
- **结论**：可复用点积、叉积及线段/多边形判定；直线求交接口存在实现问题，不能直接依赖其坐标

## 凸包Andrew.cpp

- **功能**：Andrew 凸包、保留边界共线点的变体及有向面积
- **接口**：
  - `vector<Point> convex_hull(vector<Point> p)` — 通常返回逆时针顶点，删除共线中间点，全共线时返回端点
  - `vector<Point> convex_hull_keep_col(vector<Point> p)` — 保留边界共线点；`double polygon_area(vector<Point> &p)` 返回有向面积，逆时针为正；顶点 0..n-1，无重复首点
  - `bool cmp_polar(Point a,Point b)`、`bool cmp_atan2(Point a,Point b)` — 极角比较；`int sgn(double x)`、`double cross(Point a,Point b)`、`dot`、`len(Point a)`、`len2(Point a)` 为基础运算
- **复杂度**：凸包 O(n log n) 时间、O(n) 空间；面积 O(n) 时间、O(1) 额外空间；比较 O(1)
- **最小调用示例**：
  ```cpp
  vector<Point> p={{0,0},{1,0},{0,1},{0.2,0.2}};
  auto h=convex_hull(p);
  double s=polygon_area(h);
  ```
- **注意**：输入不足 3 点时原样返回，不排序去重；keep_col 全共线会重复中间点；EPS 比较器对近邻浮点点可能不满足严格弱序，sort/unique 不应当作稳健近似去重
- **结论**：适用于凸包边界与包围面积；后续卡壳宜使用删除共线中间点的版本

## 旋转卡壳与多边形面积.cpp

- **功能**：凸包直径、最小宽度、面积周长及二分点在凸包内判定
- **接口**：
  - `vector<Point> convex_hull(vector<Point> p)` — Andrew 逆时针凸包；`double polygon_area(vector<Point> &p)` 返回有向面积；`double polygon_perimeter(vector<Point> &p)` 返回闭合边长和
  - `double rotating_diameter(vector<Point> &p)` — 返回最远点距离（非平方）；`double min_width(vector<Point> &p)` — 最小支撑线间距，≤2 点返回 0
  - `int in_convex(vector<Point> &p,Point q)` — 返回 1 内部/边界、0 外部；顶点 0..n-1，要求非空、逆时针、无重复且去除共线中间点；支持单点/线段
- **复杂度**：凸包 O(n log n) 时间、O(n) 空间；面积/周长/卡壳 O(n)，内测 O(log n)，额外空间 O(1)
- **最小调用示例**：
  ```cpp
  vector<Point> a={{0,0},{2,0},{0,2}};
  auto p=convex_hull(a);
  double d=rotating_diameter(p),w=min_width(p);
  ```
- **注意**：in_convex 不支持空集；两点周长为线段长的两倍；convex_hull 不足 3 点不去重，重复边会使宽度除零；Point 的 EPS 排序存在严格弱序风险
- **结论**：适用于点集最远距离、最窄包围带和大量凸包内测查询

## 平面最近点对.cpp

- **功能**：求二维点集中最近两点的欧氏距离
- **接口**：
  - `double closest_pair(vector<Point> a)` — 输入副本，返回距离；少于两点返回正无穷，重合点返回 0
  - `double solve(vector<Point> &a,vector<Point> &tmp,int l,int r)` — 0-indexed 半开区间 [l,r)，返回距离平方；入口按 x 排序，出口按 y 排序，tmp 至少与 a 同长
  - `double dis2(Point a,Point b)` — 距离平方；`bool cmp_y(Point a,Point b)` — 按 y 比较
- **复杂度**：O(n log n) 时间，O(n) 空间（含输入副本与归并缓冲）
- **最小调用示例**：
  ```cpp
  vector<Point> p={{0,0},{3,4},{1,0}};
  double d=closest_pair(p);
  cout<<d<<'\n';
  ```
- **注意**：直接调 solve 必须准备排序与缓冲；不要把内部返回的平方距离当距离；坐标需有限，平方运算须避免 double 溢出
- **结论**：适合大规模平面点集最近距离；当前接口只返回距离，不返回点对编号

## 最小圆覆盖.cpp

- **功能**：求覆盖全部二维点的最小圆，支持重复点与共线点
- **接口**：
  - `Circle min_circle(vector<Point> a)` — 返回 Circle{p,r}（圆心、半径），空集返回 {{0,0},0}，点下标 0..n-1
  - `Circle two(Point a,Point b)` — 两点作直径；`Circle three(Point a,Point b,Point c)` — 三点外接圆，共线时最远两点作直径
  - `double dis(Point a,Point b)` — 欧氏距离；`bool inside(Circle c,Point p)` — 距离≤r+EPS，EPS=1e-8
- **复杂度**：随机增量期望 O(n)，最坏 O(n³)，空间 O(n)（输入副本）
- **最小调用示例**：
  ```cpp
  vector<Point> p={{0,0},{2,0},{1,1}};
  Circle c=min_circle(p);
  bool ok=inside(c,p[0]);
  ```
- **注意**：内部固定种子 19260817，结果可复现；three 对非共线钝角三角形返回外接圆而非三点最小圆；近共线阈值为 |d|<1e-12，注意坐标尺度
- **结论**：适用于最小覆盖半径和设施覆盖；可直接读取圆心用于构造答案

## 半平面交.cpp

- **功能**：求若干有向直线左侧半平面的有界交集
- **接口**：
  - `Line(Point a,Point b)` — p=a、v=b-a，保留 a→b 左侧；`vector<Point> half_plane(vector<Line> a)` 返回交点多边形，顶点 0..k-1，无重复首点
  - `bool inside(Line a,Point p)` — 判断左侧或边界；`Point meet(Line a,Line b)` — 非平行直线交点
  - `double area(vector<Point> p)` — 返回绝对面积；`vector<Line> box()` — 返回 [-10,10]² 的四条边界（固定测试边界）
- **复杂度**：半平面交 O(n log n) 时间、O(n) 空间；面积 O(k) 时间，传值复制占 O(k) 空间
- **最小调用示例**：
  ```cpp
  vector<Line> a=box();
  auto p=half_plane(a);
  double s=area(p);
  ```
- **注意**：方向须非零，须按题目显式提供有界条件，不能识别所有无界情形；meet 不检查平行；注释称点/线段返回空，但实现未验面积，退化交集可能返回重复顶点
- **结论**：适用于凸多边形交集、线性约束的可行区域；返回空或退化结果时需结合面积判断

## 闵可夫斯基和.cpp

- **功能**：求两个整数凸点集的闵可夫斯基和边界
- **接口**：
  - `vector<Point> hull(vector<Point> a)` — 排序去重并删除共线中间点，返回逆时针凸包；Point 的 x、y 与 `ll cross(Point a,Point b)` 均为 ll
  - `void rotate_low(vector<Point> &a)` — 将最低 y、再最低 x 顶点旋转到首位
  - `vector<Point> minkowski(vector<Point> a,vector<Point> b)` — 输入 0-indexed 逆时针严格凸包，无重复首点；支持单点/线段，任一空集返回空集
- **复杂度**：hull O(n log n)，minkowski O(n+m)；空间分别 O(n)、O(n+m)
- **最小调用示例**：
  ```cpp
  vector<Point> a={{0,0},{1,0},{0,1}},b={{2,3}};
  a=hull(a); b=hull(b);
  auto c=minkowski(a,b);
  ```
- **注意**：任意点集先 hull；所有坐标加减与叉积须不溢出 ll；向量参数传值，不改变调用者；输出删除零边和共线中间点
- **结论**：可用于凸形状平移可达域及碰撞判断；构造 A+(-B) 可转化两凸集的相对位置问题

## 三维几何基础.cpp

- **功能**：三维向量、三点建平面、投影、线面相交及点线距离
- **接口**：
  - `double dot(Point a,Point b)`、`double len(Point a)`、`Point cross(Point a,Point b)`；Point{ x,y,z } 支持 +、-、*；Plane{p,n} 保存平面上一点和法向量
  - `bool make_plane(Point a,Point b,Point c,Plane &s)` — 非共线返回 true；`bool project(Point p,Plane s,Point &q,double &d)` — 成功输出垂足 q、非负距离 d，退化返回 false
  - `int line_plane(Point a,Point v,Plane s,Point &q)` — 直线 a+t*v：-1 退化、0 无交、1 唯一交、2 直线在平面内；`double point_line(Point p,Point a,Point v)` 返回距离
- **复杂度**：各接口 O(1) 时间、O(1) 空间
- **最小调用示例**：
  ```cpp
  Plane s; Point q; double d;
  bool ok=make_plane({0,0,0},{1,0,0},{0,1,0},s);
  if(ok) ok=project({0,0,2},s,q,d);
  ```
- **注意**：EPS=1e-9；make_plane 即使失败也写 s，project 失败不写 q/d，line_plane 仅返回 1 时写 q；零方向 point_line 按点处理
- **结论**：适用于空间投影、直线与平面位置关系和距离计算，交线段还需检查参数范围
