## 并查集.cpp

- **功能**：维护集合合并、连通性与大小
- **接口**：
  - `DSU<NMAX>`：`void init(int n)` 初始化 1..n；`int find(int x)` 返回代表元
  - `void unionn(int x,int y)`；`bool same(int x,int y)`；`int size(int x)` 返回集合大小
- **复杂度**：均摊 O(α(n))，数组空间 O(NMAX)
- **最小调用示例**：
  ```cpp
  DSU<10> d; d.init(3);
  d.unionn(1,2);
  cout << d.same(1,2) << " " << d.size(1);
  ```
- **注意**：接口名是 unionn；要求 n<NMAX，0 不初始化；采用路径压缩和按大小合并。
- **结论**：用于连通性、环判定及 Kruskal。

## 带权并查集.cpp

- **功能**：三类循环关系与势能差约束
- **接口**：
  - `KindDSU<NMAX>`：`void init(int n_)`、`int find(int x)`、`void unionn(int x,int y)`；`bool same(int x,int y)` / `bool eat(int x,int y)` 加入声明、矛盾返回 false
  - `WeightDSU<NMAX>`：`void init(int n,int m=0)`、`int find(int x)`；`bool merge(int x,int y,ll w)` 加入 val[y]-val[x]=w；`ll query(int x,int y)` 返回差或 INF
- **复杂度**：仅路径压缩、无按秩合并；保守单次 O(n)，操作序列均摊可界 O(log n)，空间 O(NMAX)
- **最小调用示例**：
  ```cpp
  WeightDSU<10> d; d.init(3);
  bool ok=d.merge(1,2,5);
  if(ok) cout << d.query(1,2);
  ```
- **注意**：元素 1..n<NMAX；KindDSU 内部 1..3n。WeightDSU 的 w/d/query 为 ll，mod=0 不取模，差及中间加法须可表示；mod>0 归一到 [0,mod)。
- **结论**：用于食物链、模差关系和差值一致性；query 不连通返回 0x3f3f3f3f。

## 笛卡尔树.cpp

- **功能**：按原序列建立小根堆笛卡尔树
- **接口**：
  - `int build_cart()` — 读取全局 n,a[1..n]，返回根编号，n=0 返回 0
  - 输出 `lc[1..n],rc[1..n],fa[1..n]`，空儿子与根父亲为 0；全局 root 须自行接收
- **复杂度**：O(n)，数组空间 O(n)
- **最小调用示例**：
  ```cpp
  n=3; a[1]=3; a[2]=1; a[3]=2;
  root=build_cart();
  cout << root;
  ```
- **注意**：相等值不弹栈，靠前者在上；函数没有提供 LCA/RMQ 接口，不应直接调用查询。
- **结论**：配合 LCA 可做区间最小值，也可用于按最小值分治。

## 动态开点线段树.cpp

- **功能**：大整数坐标域的区间加与区间和
- **接口**：
  - `DynSeg(ll lo_=1,ll hi_=1000000000)`；`void init(ll lo_,ll hi_)`；`void add(ll L,ll R,ll v)`
  - `ll sum(ll L,ll R)`；`void point_add(ll x,ll v)`；`int nodes()` 返回非哨兵结点数（含根）
- **复杂度**：每次 O(log V)；m 次修改及有标记查询最多 O(m log V) 结点

- **结论**：用于稀疏大值域计数和在线区间统计。

## 二叉搜索树.cpp

- **功能**：不重复整数集合的无旋 BST
- **接口**：
  - `BST`：`void clear()`；`int insert(int p,int x)` / `int erase(int p,int x)` 返回新根；`bool find(int p,int x)`
  - `int get_rank(int p,int x)` 返回 <x 个数；`int kth(int p,int k)` 第 k 小（1 起）缺失 0；`int get_pre(int p,int x)` / `int get_next(int p,int x)` 严格前后继、缺失 -INF/INF
- **复杂度**：单次 O(树高)，随机插入平均 O(log n)、最坏 O(n)；结点池 O(N)
- **最小调用示例**：
  ```cpp
  static BST t; t.clear(); int r=0;
  r=t.insert(r,5); r=t.insert(r,2);
  cout << t.kth(r,1);
  ```
- **注意**：重复键忽略；修改要接收返回根；clear 只清 tot，外部根要归零，0 号结点需零初始化；删除不回收结点。
- **结论**：用于有序集合；对抗性数据应选完整平衡树。

## 哈希表.cpp

- **结论**：用于整数去重与成员查询，当前实现不提供删除。

## 珂朵莉树ODT.cpp

- **功能**：set 分段维护区间赋值、加、和、计数及第 k 小
- **接口**：
  - `auto split(int pos)` 返回 set<Node>::iterator；`void assign(int l,int r,ll v)`；`void add(int l,int r,ll v)`
  - `ll query_sum(int l,int r)`；`int query_cnt(int l,int r,ll v)`；`ll query_kth(int l,int r,int k)` 第 k 小，k 超长度返回 -1
- **复杂度**：触及 s 段时加/和/计数 O(log S+s)，kth O(log S+s log s)；最坏线性段数，空间 O(S)
- **最小调用示例**：
  ```cpp
  n=3; odt.clear(); odt.insert(Node(1,n,0));
  assign(1,2,5); add(2,3,1);
  cout << query_sum(1,3);
  ```
- **注意**：必须先完整覆盖 1..n；先 split(r+1) 后 split(l) 防迭代器失效；k>=1；随机赋值可能减少段数，不能保证一般 O(log n)。
- **结论**：适用于有区间赋值、段数较少的数据；对抗性查询会退化。
- **均摊条件**：赋值会删除触及的段，遍历可按段生命周期收费；add 和查询不删段，不能因“存在赋值”就宣称总 O((n+q)log n)。

## 可持久化Treap(fhq).cpp

- **功能**：持久化隐式序列，插删、区间加、翻转和求和
- **接口**：
  - `Treap`：`int insert(int p,int k,ll v)` 在前 k 个后插入，0<=k<=长度；`int erase(int p,int k)` 删除第 k 个，1 起
  - `int update(int p,int l,int r,ll v,bool rev)` 加 v 并可翻转，返回新根；`ll range_sum(int p,int l,int r)` 闭区间和；`pair<int,int> split(int p,int k)`、`int merge(int a,int b)`
- **复杂度**：期望单次 O(log n)，最坏 O(n)；修改期望新增 O(log n)，查询无新结点
- **最小调用示例**：

## 链接剖分LCT.cpp

## 莫队算法.cpp

- **功能**：离线求区间不同整数个数
- **接口**：

## 平衡树Splay.cpp

- **功能**：多重有序集合或带哨兵的序列翻转
- **接口**：
  - `Splay::void clear()`、`void insert(int v)`、`void erase(int v)` 删一次；`int find_node(int v)` 缺失 0；`int get_rank(int v)` 为 <v 个数；`int kth(int k)` 第 k 小缺失 0
  - `int get_pre(int v)` / `int get_next(int v)` 缺失 -INF/INF；`void init(int n_)` 建 1..n_ 序列；`int get_pos(int k)` 含哨兵的中序结点编号；`void reverse(int l,int r)`
- **复杂度**：插入和序列翻转标准均摊 O(log n)；只查找不伸展的 find/rank/kth/前后继及失败删除最坏 O(n)，空间 O(N)
- **最小调用示例**：
  ```cpp
  static Splay t; t.init(4);

  ```
- **注意**：集合与序列模式不能混用；序列 i 对应中序 i+1，容量含两哨兵；get_pos 返回结点而 kth 返回值；只读查询没有 splay，不能统一声称均摊对数。
- **结论**：集合支持重复值，序列模式适用于文艺平衡树区间翻转。

  ```cpp

  t.src=a; t.mod=1000000007; t.build(1,3,1);
  t.update_mul(1,2,2,1,3,1); cout << t.query(1,3,1,3,1);
  ```
- **注意**：根区间 1,n,1；整数 T 不超过 64 位。mod>=0，正模数下余数归一，乘加中间值用 __int128；不取模时最终结果须能放入 T。
- **结论**：适合仿射区间变换与动态区间和。

## 线段树(区间开方).cpp

## 线段树合并.cpp

## 主席树(可持久化线段树).cpp

  - `int count_le(int u,int v,int l,int r,int x)` <=离散位置 x；`int cnt_value(int u,int v,int x)` 等于位置 x；`int count_range(int L,int R,int lo,int hi)` 真实值闭区间计数

## KD-Tree.cpp

## ST表.cpp

- **功能**：静态区间最大值 / 最小值

  - `T query(int l,int r)` — 返回闭区间最大 / 最小值

## 可回滚并查集与时间线段树.cpp

## 01Trie(最大异或).cpp

- **接口**：BinaryTrie(bits=32)：insert(x)、erase(x)、max_xor(x)、clear()。
- **前提与复杂度**：uint32_t，多重集；erase 删一个副本，未找到返回 false；max_xor 返回异或值，查询要求非空，若要匹配数 y 则取 x^返回值。bits<32 时输入必须小于 2^bits。单次 O(bits)，删除不回收节点。
- **结论**：整数最大异或，支持重复数与删除。

## 左偏树(可并堆).cpp

- **接口**：LeftistHeap：insert(root,x)、merge(x,y)、pop(root) 返回新根；top(root)、clear()。
- **前提与复杂度**：节点 0 为空；merge 消耗两棵旧堆，必须无共享节点；pop/top 要求非空。权值 ll，可重复，删除不回收节点。合并/插入/删顶 O(log n)，取顶 O(1)。
- **结论**：小根可并堆，右链空路径长约束。

## 整体二分(前缀判定).cpp

- **接口**：`first_connected(n,edges,queries)` 返回各点对首次连通的前缀长度；0 表示初始连通，m+1 表示无解。点 1..n，向量从 0 起，空操作和空查询均可。
- **复杂度**：O((n+m+q) log(m+2) alpha(n)) 时间，O(n+m+q) 空间。
- **用法**：每轮按 mid 分桶，重置 DSU，扫描插入。其他单调前缀模型可替换 DSU 与判定；删除操作不满足本例单调性，不能套带修改第 k 小的减 k 转移。
