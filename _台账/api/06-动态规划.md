## 背包(01完全多重).cpp

- **接口**：`knap_01 / knap_01_exact / knap_complete / knap_multiple_binary / knap_multiple_deque / knap_mixed`，返回 f[V]。
- **前提与边界**：物品 1..n，容量 0..V；重量正、0<=V<M。exact 不可达为 -INF，其他允许不装满；混合 typ=0/1/2。
- **复杂度**：01、完全、队列多重 O(nV)；二进制多重 O(VΣlog(c+1))。

## 插头DP(轮廓线).cpp

- **接口**：`ll plug_dp(int n,int m)` 数满矩形网格哈密顿回路；`ll domino_tiling(int n,int m)` 数骨牌铺法。
- **前提与边界**：不含障碍；n,m>=1，插头状态 2 bit/位，m<=12，计数须放入 ll。vis 是独立暴力测试的存储，算法不读它。
- **复杂度**：插头 O(nmSm)，S 为轮廓状态数、括号匹配 O(m)；骨牌 O(nm2^m)。

## 单调队列优化DP.cpp

- **接口**：`window_max / window_min(n,k,a,res)`；`int jump_max_score(n,L,R,a)`。
- **前提与边界**：数组 1 起；窗口答案 res[1..n-k+1]，1<=k<=n。跳跃 1<=L<=R，可从任意位置起步；n>=1、分数和须放入 int。
- **复杂度**：O(n) 时间，O(n) 工作数组。

## 递推与线性DP.cpp

- **接口**：`lis_n2 / lis_nlogn / max_subarray / triangle_max / grid_paths / lcs / climb / decode_ways`。
- **前提与边界**：数组/字符 1 起；三角形和网格每维<15；最大子段非空，n>=1；爬楼含 n=0 的空方案，解码空串返回 0。所有计数/和值须可表示。
- **复杂度**：LIS O(n²)/O(n log n)，字符串 O(nm)，网格/三角形 O(nm)/O(n²)，其他 O(n)。

## 动态DP.cpp

- **接口**：`build_all()` 从根 1 建树；`update(u,x)` 改点权；`get_f(1,f0,f1)`，答案 max(f0,f1)。
- **前提与边界**：点 1..n，1<=n<N=2005，adj 为无向树；w 为 ll。矩阵按浅×深合并；有限状态和值须远离 NEG。dfs1/dfs2 递归，长链注意栈。
- **复杂度**：建树 O(n log n)，单次修改 O(log² n)，存储 O(n)。

## 分组背包.cpp

- **接口**：`int group_knap(int g,int V)` 每组至多一件；`int depend_knap(int n,int V)` 主件+最多两附件。
- **前提与边界**：gw/gv[k][i]、mw/mv[i]、aw/av[i][1..2] 预先填写；重量正，0<=V<VMAX；允许不选。
- **复杂度**：O(V×总物品数) / O(nV)，工作数组 O(V)。

## 概率期望DP.cpp

- **接口**：`exp_hit(n,p)` 反射随机游走首次到 n 的期望；`exp_forward_walk(n,p)` 截断概率正推；`exp_forward_grid(n,m,a,b)` 二维正推；`coupon_expected(n)` 集齐等概率卡片。
- **前提与边界**：exp_hit 起点 0，n<N，p∈[0,1]，n>0/p=0 返回 -1；正推例子截断到固定轮数，只是近似，尾概率未消失时不能当精确值；二维每维<=15，a,b>=0、a+b<=1。
- **复杂度**：exp_hit 为高斯消元 O(n³)；正推 O(Tn)/O(Tnm)；集卡 O(n)。

## 矩阵优化DP.cpp

- **接口**：`solve(c,f,n)` 返回第 n 项，固定 MOD=1000000007；递推为 f(n)=c[0]f(n-1)+...+c[k-1]f(n-k)。
- **前提与边界**：c 和 f 都长 k>0；f 存初值 f(0)..f(k-1)，n>=0；系数和初值可为负数。
- **复杂度**：k 阶递推 O(k³ log n)，空间 O(k²)。

## 区间DP.cpp

- **接口**：`stone_merge_min / stone_merge_max(n,a)`；`energy_necklace(n,a)`；`polygon_game(n,val,op)`。
- **前提与边界**：1 下标，n>=1；石子非负、项链值正，前两类会复制输入到 a[n+1..2n+1]，需 2n+1<N。多边形 op[i] 连接 i 与 i+1；中间积及和须放入 int。
- **复杂度**：前三者 O(n³)，多边形枚举断边 O(n⁴)，空间 O(n²)。

## 树形DP.cpp

- **接口**：`dfs_party(root)`，答案 max(dp[root][0],dp[root][1])；`dfs_knap(0)`，答案 f[0][m]；`dfs_dia(root)` 更新 dia。
- **前提与边界**：son 是有根子树；选课用虚拟根 0，恰好选 m 门，选子先选父，负学分可用，不可达为 NEG。每次求直径先 dia=0；递归深度可达 n。
- **复杂度**：舞会/直径 O(n)，树背包 O(nm²) 上界；f 空间 O(nm)。

## 数位DP.cpp

- **接口**：`solve_cnt(x,d)` 数 1..x 中数字 d 的出现次数；`solve_no4(x)`、`solve_windy(x)`、`solve_sumk(x,k)` 数 0..x 合法数。
- **前提与边界**：x<0 返回 0；后三者包含数 0；缓存与参数由 solve 重置。区间用 solve(r)-solve(l-1)，全部计数须放入 ll。
- **复杂度**：位数 D≤19，状态为 D、D×前一位或 D×数位和；每状态枚举十个数字。

## 四边形不等式与决策单调性.cpp

- **接口**：`dnc_partition(n,K,cost,f,opt)`；`mq_layer(n,cost)` 用 fd[1] 求 fd[2]。
- **前提与边界**：分成 K 个非空连续段；cost[l][r] 为段代价，1<=K<=n<N。分治需最优决策单调；队列还需新决策胜出区间为后缀。示例非负数组的段和平方满足；数值及加法<INF。
- **复杂度**：分治 O(Kn log n)，单层分界队列 O(n log n)。

## 斜率优化DP.cpp

- **接口**：`slope_dp(n,L,a)` 返回 f[n]；`slope_dp_all(n,L,a,f)` 填所有 f；`build_ab` 展开直线形式。
- **前提与边界**：f[i]=min_{j<i} f[j]+(s[i]-s[j]-L)²；a>=0，前缀和单调，支持零增量；平方、k、f/y 等仍需放入 ll，比较交叉乘积用 __int128。
- **复杂度**：单调查询/加点 O(n)，空间 O(n)；加点无序时换李超树或一般凸壳。

## 状压DP.cpp

- **接口**：`int artillery(n,m)` 炮兵；`double tsp(n)` 从原点访问全部给定点的最短路。
- **前提与边界**：炮兵 mp[i] 的 1 位为山地，m<=10；TSP 由 px/py[1..n] 给点，0 为原点，n<=15，不要求回起点，n=0 返回 0。
- **复杂度**：炮兵 O(nS³)，S 为合法行状态数；TSP O(2^n n²)。

## 最长公共子序列LCS.cpp

- **接口**：`lcs_nm / lcs_roll / lcs_scheme / edit_dist / edit_dist_roll / lcsubstr(n,m,a,b)`。
- **前提与边界**：字符数组 1 起；LCS 方案打印一组最优子序列；编辑距离的增删改代价各 1；lcsubstr 求连续公共子串。
- **复杂度**：O(nm) 时间，完整表 O(nm) 空间，滚动 O(m)。

## 最长上升子序列LIS.cpp

- **接口**：`lis_n2 / lis_nlogn / lnds_nlogn / lds_nlogn(n,a)`；`lcs_perm(n,a,b)`；`lis_scheme(n,a)`。
- **前提与边界**：1 下标；严格上升用 lower_bound，不降用 upper_bound，下降用降序比较器；支持 INT_MIN/MAX。排列 LCS 要两排列都为 1..n，方案函数打印结果。
- **复杂度**：LIS O(n²)/O(n log n)，排列 LCS O(n log n)，方案 O(n²)。
