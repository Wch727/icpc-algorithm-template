## 背包(01完全多重).cpp

- **功能**：01、完全、多重和混合背包最大价值，另提供恰好装满的 01 背包。
- **接口**：`int knap_01(int n,int V,int w[],int v[])`、`int knap_01_exact(int n,int V,int w[],int v[])`、`int knap_complete(int n,int V,int w[],int v[])`；`int knap_multiple_binary(int n,int V,int w[],int v[],int c[])`、`int knap_multiple_deque(int n,int V,int w[],int v[],int c[])`；`int knap_mixed(int n,int V,int w[],int v[],int c[],int typ[])`。均返回 f[V]，exact 不可达返回 -INF。
- **复杂度**：01/完全/队列多重 O(nV)，二进制多重 O(VΣlog(c[i]+1))，混合 O(V(n+Σ多重log(c[i]+1)))；使用固定 O(M) 工作空间。
- **最小调用示例**：
  ```cpp
  int w[3]={0,2,3},v[3]={0,4,5};
  int best=knap_01(2,4,w,v);
  int exact=knap_01_exact(2,4,w,v);
  ```
- **注意**：物品数组 1..n，容量 f[0..V]，0<=V<M=100005；重量须正，数量非负，价值和及拆分乘积须装 int；typ 为 0/1/2（代码将其他值也当多重）。每次调用清 f，除 exact 外均允许不装满。
- **结论**：容量约束下选物；按件数限制选择对应接口，恰好装满必须使用 exact 初始化。

## 矩阵优化DP.cpp

- **功能**：求常系数 k 阶递推 f(n)，模 1000000007。
- **接口**：`Matrix(int n_,bool unit=false)` 建零矩阵/单位阵；`Matrix mul(const Matrix &a,const Matrix &b)`、`Matrix qpow(Matrix a,ll n)`；`ll solve(const vector<ll> &c,const vector<ll> &f,ll n)` 返回递推值。
- **复杂度**：solve O(k³ log n)，空间 O(k²)；n<k 直接返回初值，O(1)。
- **最小调用示例**：
  ```cpp
  vector<ll> c={1,1};
  vector<ll> initial={0,1};
  ll ans=solve(c,initial,10);
  ```
- **注意**：c[i] 乘 f(n-1-i)，初值为 f[0..k-1]；要求 k>0、初值长度=k、n>=0；矩阵下标 0..k-1，mul 要同阶；solve 归一化负输入，直接 mul 要自行规范系数。
- **结论**：适合巨大项号的线性递推、多状态固定转移。

## 数位DP.cpp

- **功能**：统计数字出现次数、不含 4、相邻位差至少 2、数位和不超过 k 的前缀答案。
- **接口**：`ll solve_cnt(ll x,int dd)`、`ll solve_no4(ll x)`、`ll solve_windy(ll x)`、`ll solve_sumk(ll x,int k)` 均统计 [0,x]，x<0 返回 0；`void get_dig(ll x)` 写 dig[1..len]，dig[1] 为个位。
- **复杂度**：D 为位数，前三项 O(10D)/O(100D)，数位和 O(10D·min(k+1,9D+1))；每次清固定缓存，空间按表 O(N·205)，N=25。
- **最小调用示例**：
  ```cpp
  ll l=1,r=100;
  ll count=solve_no4(r)-solve_no4(l-1);
  ll digits=solve_cnt(r,0)-solve_cnt(l-1,0);
  ```
- **注意**：dd 应为 0..9；no4/windy/sumk 包含整数 0，cnt 不计前导零且整数 0 自身也贡献 0 次；k<0 返回 0，sum 下标须<205（ll 非负输入最多 19 位，数位和<=171）；次数/个数可能超 ll。包装函数每次重置缓存，内部 dfs 不宜直接调用。
- **结论**：区间用 solve(r)-solve(l-1)，可按新增状态扩展十进制限制计数。
