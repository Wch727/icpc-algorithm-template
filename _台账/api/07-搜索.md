## A星与K短路.cpp

- **功能**：在非负权有向图中求第 k 短的游走长度，允许重复经过顶点
- **接口**：
  - `void Graph::init(int n)`、`void Graph::add_edge(int u,int v,int w)` — 初始化并加边；顶点用 1..n，须同时构造正图 `g` 与反图 `rg`
  - `void dijkstra_rev(int src)` — 使用全局 n、rg，写入到 src 的距离 `h[1..n]`
  - `ll kth_shortest(int s,int t,int kk)` — kk 从 1 开始；不足 kk 条返回 -1，同长游走分别计数，s=t 时空路径算第 1 条
- **复杂度**：反图最短路 O(m log n)，游走枚举 O(km log(km)) 上界；八数码 O(S log S)。
- **最小调用示例**：
  ```cpp
  n=3; g.init(n); rg.init(n);
  g.add_edge(1,3,7); rg.add_edge(3,1,7);
  ll ans=kth_shortest(1,3,1);
  ```
- **注意**：n<N=1005；正反图使用 vector，权值非负，距离/答案为 ll，有限路径及估价和须<INF；不扩展不能到终点的后继。另有 astar_puzzle，八数码下标 0..2，错位估价排除空格。
- **结论**：适用于允许绕环的第 k 短路；不能直接当作第 k 条简单路径算法

## BFS最短路.cpp

- **功能**：提供四邻网格、马步多源、泛洪、流星雨和八数码搜索
- **接口**：
  - `void bfs_grid(int sx,int sy)` — 使用 n、m、block，写 dis；`void bfs_multi(vector<pair<int,int> > src)` — 马步写 md，不检查 block；两者网格均为 1..n、1..m，未到达为 -1
  - `void flood(int x,int y,int c)` — 四邻染色零格，范围含 0..n+1、0..m+1；`int bfs_meteor()` — tim 上从 (0,0) 到永久安全格，返回最早时刻或 -1
  - `ll encode(int b[3][3])`、`void decode(ll s,int b[3][3])`、`ll flip(ll s,int p,int q)` — 棋盘下标 0..2、格号 0..8；`int bfs_puzzle(int st[3][3])` 返回到 123456780 的步数或 -1
- **复杂度**：网格 O(nm)，流星雨 O(N²)，八数码用 map 为 O(S log S)；空间分别 O(N²)、O(S)，N=405
- **最小调用示例**：
  ```cpp
  n=3; m=3; memset(block,0,sizeof(block));
  bfs_grid(1,1);
  int steps=dis[3][3];
  ```
- **注意**：bfs_grid 拒绝障碍起点；多源起点须合法；flood 的 c 非零且 n+1,m+1<N；流星雨 tim 先置 INF，再取最早毁坏时间。
- **结论**：可用于等权最短路、最近源距离和连通块；马步与四邻移动规则需按所选接口区分

## DFS与剪枝.cpp

- **功能**：枚举排列、组合、子集，并计数组合素数和、N 皇后及最小分组差
- **接口**：
  - `void dfs_perm(int dep)` — 从 1 开始并直接打印排列；`void dfs_comb(int dep,int idx)` — 从 (0,1) 累加 comb_cnt；`void dfs_subset(int idx)` — 从 1 累加 sub_cnt；`void mask_subset()` 的选中分支为空
  - `bool is_prime(int x)`、`void dfs_prime(int step,int sum,int idx)` — 从 (0,0,0) 累加 prime_cnt，读取 a[0..n-1]；`void dfs_queen(int r)` — 从 1 累加 cnt_queen，使用 nn
  - `void dfs_split(int idx,int s1,int s2)` — 从 (1,0,0) 更新 best，读取 a[1..n] 与包含当前项的 sum_rest[idx]
- **复杂度**：排列输出 O(n·n!)，子集 O(2^n)，掩码 O(n2^n)，素数组合 O(k·C(n,k)+C(n,k)√M)，皇后最坏 O(nn·nn!)，分组 O(2^n)；递归空间 O(n)
- **最小调用示例**：
  ```cpp
  n=3; a[1]=1; a[2]=2; a[3]=4; best=INT_MAX;
  sum_rest[3]=4; sum_rest[2]=6; sum_rest[1]=7;
  dfs_split(1,0,0);
  ```
- **注意**：N=15，1-indexed 时 n、nn≤14；分组剪枝要求非负数；计数器和标记自行重置，int 计数/和可能溢出，素数试除 i*i 也有溢出风险
- **结论**：适合小规模枚举和分支限界；子集接口仅计数，若需输出选中元素须另加状态

## DLX舞蹈链.cpp

- **功能**：求稀疏 0/1 矩阵的一个精确覆盖方案，每列恰好被覆盖一次
- **接口**：
  - `void Dlx::init(int n)` — n 是列数，列号 1..n，0 是链表哨兵
  - `void Dlx::add_row(int id,const vector<int> &a)` — 添加行，a 是该行包含的列号；id 为调用者指定的行标识
  - `bool Dlx::solve()` — 有解返回 true，选中的行标识存入 ans；`bool dance()`、`void remove(int c)`、`void resume(int c)` 为搜索/链表辅助接口
- **复杂度**：建表 O(n+Z)，搜索最坏指数时间；表空间 O(n+Z)，递归与答案空间 O(n)，Z 为非零项数
- **最小调用示例**：
  ```cpp
  Dlx d; d.init(2);
  d.add_row(10,{1}); d.add_row(20,{2});
  bool ok=d.solve(); // ok 时读取 d.ans
  ```
- **注意**：一行列号不能重复，空行不会被选中；solve 会清 ans 并恢复链表，可重复调用；不要自行破坏 remove/resume 的配对顺序
- **结论**：可把数独、拼板和满足“恰好一次”的选择问题建成精确覆盖

## 双向BFS.cpp

- **功能**：用双向搜索求四邻迷宫或逐位数字加一变换的最少步数
- **接口**：
  - `int bibfs_grid(int sx,int sy,int ex,int ey)` — 使用 n、m、mp[1..n][1..m]，墙为 '#'; 返回步数，墙起终点或不可达返回 -1
  - `ull step_digit(ull s,int k,int delta=1)` — 第 k 位从低位 0 开始，每位占 4 bit，返回变换后的编码；反向用 delta=-1
  - `int bibfs_num(ull s,ull t)` — 使用全局 dig，正向每位模 10 加一，反向枚举减一；返回最少步数或 -1
- **复杂度**：网格搜索 O(nm)，含固定数组清零为 O(N²)，空间 O(N²)；数字搜索期望 O(dig·10^dig)，空间 O(10^dig)
- **最小调用示例**：
  ```cpp
  dig=2;
  ull s=0x09,t=0x10; // 十六进制半字节存十进制数字
  int ans=bibfs_num(s,t);
  ```
- **注意**：N=1005，n、m≤1004，传入坐标须合法；数字每位必须为 0..9，dig≤16（实际建议≤6）；相同起终点的提前返回不清旧距离表
- **结论**：适合已知终态的等权状态搜索；有向操作必须正确生成反向前驱

## 折半搜索.cpp

- **功能**：统计元素子集和等于 target 的方案数，支持负数和重复元素
- **接口**：
  - `vector<ll> enum_sum(const vector<ll> &a,int l,int r)` — 枚举 0-indexed 半开区间 [l,r) 的所有子集和，包含空集且保留重复和
  - `ll solve(const vector<ll> &a,ll target)` — 返回方案数，按元素位置区分子集
- **复杂度**：O(n·2^(n/2)) 时间，O(2^(n/2)) 空间
- **最小调用示例**：
  ```cpp
  vector<ll> a={-1,1,2};
  ll ans=solve(a,2);
  auto sums=enum_sum(a,0,2);
  ```
- **注意**：源码建议 n≤40；target=0 时空集计入；区间必须合法，所有子集和须在 ll 范围内，target-x 用 __int128 比较
- **结论**：适用于元素数中等、值域很大而无法做普通背包的精确子集计数

## 模拟退火与爬山.cpp

- **功能**：在 [-10,10]² 内启发式最小化 (x-cx)²+2(y-cy)²
- **接口**：
  - `Optimizer(double x,double y,unsigned seed)` — 设置 cx、cy 与随机种子；`double value(Point p)` 返回目标值
  - `double rnd()` — 生成 [0,1) 随机数；`Point clamp(Point p)` — 把坐标裁剪到边界
  - `Point anneal(Point cur)` — 返回退火期间最佳点；`Point climb(Point cur)` — 返回逐级减小步长后的点
- **复杂度**：退火 O(20L) 次常数目标计算；爬山 O(9I)，I 为各尺度总轮数；额外空间 O(1)
- **最小调用示例**：
  ```cpp
  Optimizer opt(2,3,42);
  Point p=opt.anneal({0,0});
  p=opt.climb(p);
  ```
- **注意**：起点应先保证在区域内（接口不先 clamp 起点）；退火温度 10→1e-5、乘 0.98，爬山步长 10→1e-8、减半；换目标需重调参数
- **结论**：可作为连续优化的启发式框架；更换非凸目标后不能保证全局最优

## 迭代加深与IDA星.cpp

- **功能**：提供加减凑数 IDDFS、5×5 马步交换和模 4 旋钮的深度迭代搜索
- **接口**：
  - `int solve_iddfs(ll target)`、`bool id_dfs(int dep,int lim,ll cur,ll target)` — 读取 id_n、id_a[1..id_n]、id_vis；返回首次成功的 lim 或 -1
  - `int ks_solve(int maxdepth)`、`void ks_dfs(int x,int y,int g,int pre)`、`int ks_h()` — 读取 ks、ks_goal[0..4][0..4] 与空格 ks_sx、ks_sy，返回找到的深度或 -1
  - `int cr_solve(int maxdepth)`、`void cr_dfs(int g,int pre)`、`int cr_h()` — 读取 cr_n、cr_s/cr_t[1..cr_n]，操作自身和指向旋钮加一模 4，返回找到的深度或 -1
- **复杂度**：凑数最坏 O(2^n·n!)，栈 O(n)；两类 IDA 搜索最坏指数时间（分支≤8 或 cr_n），栈 O(maxdepth)
- **最小调用示例**：
  ```cpp
  id_n=2; id_a[1]=3; id_a[2]=5;
  memset(id_vis,0,sizeof(id_vis));
  int ans=solve_iddfs(8);
  ```
- **注意**：id_n<=24，solve 重置并恢复选择标记，target=0 返回 0；骑士局面必须恰有一个 -1 空格，两局面棋子数一致，估价排除空格；旋钮 0..3、cr_t 合法，自指向和连续同旋钮可用。
- **结论**：可参考迭代加深与估价剪枝的接口组织；当前两个 IDA 分支不能按注释当作可靠最少步数求解器
