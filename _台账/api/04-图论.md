## 2-SAT.cpp

- **功能**：求二元布尔子句的可行赋值
- **接口**：
  - `int id(int x,int v)` 映射变量；`void add_clause(int x,int vx,int y,int vy)` 加或子句；`int solve()` 返回 1 有解、0 无解，解在 val[1..n]；`int solve_lex()` 求字典序最小解；`void clear_all()` 清图和状态
- **复杂度**：时间 O(n+m)，空间 O(n+m)
- **最小调用示例**：
  ```cpp
  n=2; clear_all();
  add_clause(1,1,2,0);
  int ok=solve();
  ```
- **注意**：变量 1..n，真结点 1..n、假结点 n+1..2n，2*n<N；solve 自动重置 SCC 状态但保留图。solve_lex 按变量顺序优先 0，O(n(n+m))，会追加 n 条固定条件；clear_all 按当前 n 清空。
- **结论**：布尔选择、互斥与蕴含约束。

## 差分约束.cpp

- **功能**：求差值不等式的一组可行解
- **接口**：
  - `void add_leq(int u,int v,ll c)` 加 x_v-x_u<=c；`void add_geq(int u,int v,ll c)` 加 >=c；`int solve()` 返回 1 有解、0 无解；`int spfa(int s)` 返回 1 表示负环；`void clear_all()` 清图
- **复杂度**：最坏 O(nm)，空间 O(n+m)
- **最小调用示例**：
  ```cpp
  n=2; clear_all();
  add_leq(1,2,3);
  int ok=solve();
  ```
- **注意**：变量 1..n，0 为超级源；解在 dis[1..n]；solve 会追加 n 条边，须预留边容量并避免反复追加。
- **结论**：排程、相对大小和前缀和约束。

## 存图(vector邻接表).cpp

- **接口**：`vector<Edge> adj[N]`，Edge 为 `{to,w}`；`add_edge(u,v,w)` 加有向边，`add_undirected` 加两个方向。
- **使用**：`for(auto [v,w]:adj[u])` 遍历；重建时清每个 adj[u]。
- **注意**：1..n<N；无向边存两次，重边/反向边需另加 id，不通过端点判断是哪条边。
- **复杂度**：加边均摊 O(1)，遍历 O(n+m)。

## 点分治.cpp

## 二分图判定.cpp

- **结论**：二分图分组、奇环检测及匹配前置判定。

## 欧拉路径与欧拉回路.cpp

## 上下界网络流.cpp

## Floyd.cpp

- **功能**：求全源最短路及布尔传递闭包
- **接口**：
  - `void floyd()` 原地更新 d[1..n][1..n]；`void closure()` 原地更新 reach[1..n][1..n]
- **复杂度**：时间 O(n³)，空间 O(n²)
- **最小调用示例**：
  ```cpp
  n=2; for(int i=1;i<=n;i++) for(int j=1;j<=n;j++) d[i][j]=i==j?0:INF;
  d[1][2]=3; floyd();
  ll ans=d[1][2];
  ```
- **注意**：点 1..n；重边取最小值。只有两段都可达才相加；要求无负环，有限距离及其加法须放入 ll。
- **结论**：小图全源距离与可达性分析。

## KM算法(最大权匹配).cpp

- **功能**：求二分图最大权完美匹配
- **接口**：
  - `ll km()` 返回权和，match[v] 为右侧 v 的左侧搭档；`int dfs(int u)` 返回相等边增广是否成功；权矩阵 w[1..n][1..n]
- **复杂度**：本版每次调顶标后重新 DFS，最坏 O(n⁴)，空间 O(n²)。
- **最小调用示例**：
  ```cpp
  n=2;
  w[1][1]=3; w[1][2]=1; w[2][1]=2; w[2][2]=4;
  ll ans=km();
  ```
- **注意**：左右各 n 个点，编号 1..n；缺边用足够小的权代替，要求真实完美匹配存在，代码不另判无解；负权可用。
- **结论**：最优指派、方阵收益最大化。

## LCA(倍增).cpp

- **功能**：求最近公共祖先、无权距离与边路径差分
- **接口**：
  - `void add_undirected(int u,int v)` 加双向边；`void dfs(int u,int f)` 预处理；`int lca(int x,int y)`、`int dist(int x,int y)` 返回祖先/边数距离；`void add_path(int x,int y)` 标记；`void collect(int u,int f)` 汇总
- **复杂度**：预处理 O(n log n)，查询/标记 O(log n)，汇总 O(n)，空间 O(n log n)
- **最小调用示例**：
  ```cpp
  n=2; add_undirected(1,2); dfs(1,0);
  add_path(1,2); collect(1,0);
  int ans=diff[2];
  ```
- **注意**：点 1..n，父亲哨兵 0；倍增 20 层，深链递归可能爆栈；diff[u] 是父边覆盖次数，根没有父边，非点差分。
- **结论**：树上距离、多条路径边覆盖统计。

## SPFA.cpp

- **功能**：队列松弛单源最短路并以入队次数检测负环
- **接口**：
  - `int spfa(int s)` 返回 1 表示入队计数达到 n、0 正常结束；距离写 dis[1..n]，adj[u] 存 Edge{int to,w}
- **复杂度**：最坏时间 O(nm)，空间 O(n+m)
- **最小调用示例**：
  ```cpp
  n=2; adj[1].push_back({2,-3});
  int bad=spfa(1);
  ll ans=dis[2];
  ```
- **注意**：点 1..n，不可达为 INF；cnt 保存松弛路径边数，达到 n 判可达负环。最坏 O(nm)，不能依赖“平均线性”保证。
- **结论**：负边最短路参考；严谨负环判定可用同目录 Bellman-Ford。

## Tarjan割点与桥.cpp

- **功能**：求无向图割点与桥
- **接口**：
  - `void add_undirected(int u,int v)` 加成对边；`void tarjan(int u,int fa)` 的 fa 是入边编号，根传 0；is_cut[u] 标割点，ea/eb[1..ecnt] 列桥，cut_edge 标桥边
- **复杂度**：时间 O(n+m)，空间 O(n+m)
- **最小调用示例**：
  ```cpp
    n=2; num=1; cut_edge.assign(2,0); add_undirected(1,2);
  for(int u=1;u<=n;u++) if(!dfn[u]) tarjan(u,0);
  int bridges=ecnt;
  ```
- **注意**：vector 邻接表 g 保存 {目标,有向边编号}；num 初值及重建值为 1，边从 2 成对加入。cut_edge 按边数动态扩展；重建时清 g、数组及计数，并 cut_edge.assign(2,0)。仅跳父边反向，支持重边；树边更新 low[v]，已访问邻点更新 dfn[v]。
- **结论**：无向连通性薄弱点、桥树与割点分析。

## Tarjan强连通分量.cpp

- **功能**：求有向图强连通分量
- **接口**：
  - `void add_edge(int u,int v)` 加有向边；`void tarjan(int u)` 写 belong[u]、sz[1..scc_cnt] 和 scc_cnt；`void add_undirected(int u,int v)` 加双向边
- **复杂度**：时间 O(n+m)，空间 O(n+m)
- **最小调用示例**：
  ```cpp
  n=2; add_edge(1,2);
  for(int u=1;u<=n;u++) if(!dfn[u]) tarjan(u);
  int ans=scc_cnt;
  ```
- **注意**：点 1..n，分量 1..scc_cnt 为出栈顺序；dag/val/dp 只有声明，未提供缩点建图或 DAG DP 函数；多组需清计数及数组，递归有栈风险。
- **结论**：SCC 缩点、互相可达分析及 DAG 化建模。

## 01BFS.cpp

- **接口**：bfs01(adj,s) 返回距离数组；adj[u] 为 vector<pair<int,int>>，存 {v,w}。
- **前提与复杂度**：点编号为 adj 的合法下标，支持 0 起；w 只能为 0/1；不可达为 INF。O(n+m)，空间 O(n+m)。
- **结论**：零边入队首、一边入队尾；不能用普通 BFS 的首次访问标记。

## 二分图最小点覆盖.cpp

- **接口**：vertex_cover(adj,match) 返回左右点覆盖编号列表。
- **前提与复杂度**：adj[1..nl] 存右邻居；match[1..nr] 存右点匹配的左点，0 表示未匹配；必须是合法最大匹配。O(n+m)，空间 O(n)。
- **结论**：最小点覆盖=未到达左点+到达右点；补集为最大独立集。

## 树同构(AHU).cpp

- **接口**：same_tree(a,b) 精确判断两棵无根无标号树是否同构；tree_code(adj,root,ids) 编号，比较时 ids 必须共享。
- **前提与复杂度**：vector 邻接表，点 1..n，合法无向树；长度 1 的 adj 表示空树。迭代遍历避免长链栈溢出；O(n log n)，空间 O(n)，无随机哈希碰撞。
- **结论**：重心取根，排序子树类型后精确编号。

## Kruskal重构树.cpp

- **接口**：`KruskalTree(n,vector<KruskalTree::Edge> edges)`；点 1..n、n>=1。`lca(u,v)` 异连通块为 0，否则为重构树 LCA；`val[lca]` 是异点之间最小瓶颈，`component(u,w)` 返回边权<=w 的连通块根，`cnt[root]` 为原点数。
- **复杂度**：构建 O(m log m+n log n)，单次查询 O(log n)，空间 O(m+n log n)。
- **注意**：支持负权、重边、同权和森林；同点路径无边，不能把叶子 LLONG_MIN 当作题目定义的距离。静态边权，修改需重建；父子邻接保存在 vector ch 中。

## 线段树优化建图.cpp

- **接口**：`RangeGraph(n)`，n>0；`add_edge(u,v,w)`；`point_to_range(u,l,r,w)`；`range_to_point(l,r,u,w)`；`range_to_range(l,r,L,R,w)`。原点 1..n，区间闭合，l>r 为空。
- **复杂度**：基础建图 O(n)，一次区间连边 O(log n)，总 O(n+q) 点、O(n+q log n) 边。
- **注意**：vector 邻接表 g 的元素为 {目标,权}；最短路数组按 g.size() 分配。出树向下、入树向上；用于网络流须把辅助树边转为 INF 容量，用于 2-SAT 须保留完整逆否约束。
