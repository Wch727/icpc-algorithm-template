## bitset优化技巧.cpp

- **功能**：位并行子集和、传递闭包及小全集子集计数
- **接口**：
  - `bitset<N> subset_sum(const vector<int> &a)` — N=513，a 非负；返回 f，f[s] 表示和 s 可达，s=0..512，包含空集
  - `void closure(vector<bitset<N> > &g)` — n=g.size()≤N，顶点 0..n-1，原地求可达性并加入自环
  - `unsigned long long count_subset(unsigned mask,unsigned allow)` — 返回 mask 的子集中同时包含于 allow 的个数，包含空集
- **复杂度**：子集和 O(|a|·N/W)，闭包 O(n²·N/W)，子集计数 O(1)；返回/闭包数据空间 O(N)、O(nN) bit，W 为机器字长
- **最小调用示例**：
  ```cpp
  auto f=subset_sum(vector<int>{2,3});
  bool can=f[5];
  auto ways=count_subset(7u,3u);
  ```
- **注意**：位移会截断≥N 的和，非负输入下不会影响小于 N 的可达性；closure 只以 0..n-1 为中转点，输入高位应清零；子集计数等于 2^popcount(mask&allow)
- **结论**：适用于有限值域背包和稠密图可达性；小全集关系可用位运算检查

## 交互题模板.cpp

- **功能**：演示询问/回答输出与本地第 m 小值假交互器
- **接口**：
  - `int ask(const string &s)` — 输出 s 并 flush，然后从 cin 读取 int；`void answer(int v)` 输出 "! v" 并 flush；`void solve()` 读取 n、m 后询问 "? m mid"
  - `void judge::init(const char *data)` — 字符串格式 n m 后接 n 个数，a[1..n]；`int judge::reply(const string &s)` — "? k v" 返回第 k 小是否>v（0/1），次数超限或不合法命令/k 返回 INT_MIN
  - `bool judge::check_answer(const string &s)` — 检查 "! v" 是否为第 m 小；init 将 qcnt=0、limit=100000
- **复杂度**：solve 约 O(log 10^9) 次询问；假交互器每次排序 O(n log n)、空间 O(n)；存储 a 的容量 N=100005
- **最小调用示例**：
  ```cpp
  judge::init("3 2 8 1 5");
  int r=judge::reply("? 2 4");
  bool ok=judge::check_answer("! 5");
  ```
- **注意**：ask 不接入 judge，实际走标准输入输出；solve 适用于已知答案在 [0,10^9] 的该协议。读入失败或 -1 终止程序；其他错误码、多测结束方式须按题目调整。judge 校验命令格式，要求 1≤m≤n<N
- **结论**：可参考刷新输出和本地协议模拟；真实题须按交互规则、值域及错误响应调整

## 随机数与对拍.cpp

- **接口**：mt19937_64 rnd，randint(l,r) 返回 ll 闭区间均匀随机数，l<=r；修改全局 seed 可复现。
- **对拍**：实现 gen()/solve(vector<ll>)/brute(vector<ll>) 后调用 stress(rounds)；每轮两份独立输入副本，遇到不同立即返回 false，打印种子、组号、结果与完整输入。
- **边界**：默认向量输入、整数答案；图/矩阵改数据类型和打印，浮点题按要求比较误差。生成器应覆盖最小规模、重复、单调、极值等情况；暴力保持独立思路。
- **其他**：附 shuffle 排列示例及 Windows bat 双进程对拍；字节比较只适用于格式一致的输出。stress 从 seed 重置随机引擎，各次同种子可复现首组数据。
