## bitset优化技巧.cpp

- **功能**：位并行子集和、传递闭包及小全集子集计数
- **接口**：
  - `bitset<N> subset_sum(const vector<int> &a)` — N=513，a 非负；返回 f，f[s] 表示和 s 可达，s=0..512，包含空集
  - `void closure(vector<bitset<N> > &g)` — n=g.size()≤N，顶点 0..n-1，原地求可达性并加入自环
  - `int count_subset(unsigned mask,unsigned allow)` — 返回 mask 的子集中同时包含于 allow 的个数，包含空集
- **复杂度**：子集和 O(|a|·N/W)，闭包 O(n²·N/W)，子集计数 O(2^popcount(mask))；返回/闭包数据空间 O(N)、O(nN) bit，W 为机器字长
- **最小调用示例**：
  ```cpp
  auto f=subset_sum(vector<int>{2,3});
  bool can=f[5];
  int ways=count_subset(7u,3u);
  ```
- **注意**：位移会截断≥N 的和，须确认所需和范围；closure 只以 0..n-1 为中转点，输入高位应清零；count_subset 的 int 结果可能溢出
- **结论**：适用于有限值域背包和稠密图可达性；小全集关系可用位运算检查

## 交互题模板.cpp

- **功能**：演示询问/回答输出与本地第 m 小值假交互器
- **接口**：
  - `int ask(const string &s)` — 输出 s 并 flush，然后从 cin 读取 int；`void answer(int v)` 输出 "! v" 并 flush；`void solve()` 读取 n、m 后询问 "? m mid"
  - `void judge::init(const char *data)` — 字符串格式 n m 后接 n 个数，a[1..n]；`int judge::reply(const string &s)` — "? k v" 返回第 k 小是否>v（0/1），次数超限或不合法命令/k 返回 INT_MIN
  - `bool judge::check_answer(const string &s)` — 检查 "! v" 是否为第 m 小；init 将 qcnt=0、limit=100000
- **复杂度**：solve 约 O(log 10^9) 次询问；假交互器每次排序 O(n log n)、空间 O(n)；存储 a 的容量 N=100005
- **最小调用示例**：
  ```cpp
  judge::init("3 2 8 1 5");
  int r=judge::reply("? 2 4");
  bool ok=judge::check_answer("! 5");
  ```
- **注意**：ask 不接入 judge，实际走标准输入输出；solve 仅对答案在 [1,10^9] 的该协议成立，答案 0 会输出 1；未处理读入失败/错误码，judge 也未完整校验格式，须保证 1≤m≤n<N
- **结论**：可参考刷新输出和本地协议模拟；真实题须按交互规则、值域及错误响应调整

## 卡常技巧.cpp

- **功能**：整数快读、缓冲快写、简单位运算及循环展开求和
- **接口**：
  - `int read()`、`ll readll()` — 从 stdin 读取有符号整数；`void write_int(int x)`、`void write_ll(ll x)` — 写入全局 obuf，无分隔；`void flush_out()` 写 stdout 并清 olen
  - `int mod_pow2(int x)` — x&1023；`int add_mod(int a,int b,int mod)` — 一次减模；`int lowbit(int x)`、`static inline int sqr(int x)`；宏 `MIN(a,b)`、`MAX(a,b)`
  - `ll sum_unrolled(int *a,int n)` — 求 a[1..n] 和；`double time_ms(function<void()> f)` — 执行 f 一次并返回毫秒
- **复杂度**：读写 O(位数)，求和 O(n)，标量辅助 O(1)，计时为 f 的耗时；obuf 固定 2^25 字节，求和额外空间 O(1)
- **最小调用示例**：
  ```cpp
  int x=read();
  write_int(x); obuf[olen++]='\n';
  flush_out();
  ```
- **注意**：读入 EOF 不退出；最小负数的取负/正数累积可能溢出；obuf 不自动检查容量/刷新；add_mod 要求 0≤a,b<mod 且和不溢出，宏参数可能求值两次
- **结论**：适合已定位到 I/O 或循环瓶颈的优化；time_ms 可测实际收益，性能倍率不是接口保证

## 容斥原理与排列组合.cpp

- **功能**：模素数组合数、错排、多重集排列与整数整除容斥
- **接口**：
  - `ll qpow(ll a,ll n)` — 模 MOD=1000000007 的幂；`void init(int n)` — 预处理 fac 与逆阶乘 inv，下标 0..n，要求 0≤n<N=100005
  - `ll C(int n,int m)` — 返回模组合数，m<0 或 m>n 返回 0；`ll derange(int n)` — 模错排数，n=0 返回 1；`ll multiset_count(const vector<int> &cnt)` — 模多重集排列数
  - `ll avoid(ll n,const vector<ll> &d)` — 返回 [1,n] 中不被任一 d[i] 整除的数量（不取模），d[i]>0，d.size()<25
- **复杂度**：init O(n+log MOD)，C O(1)，derange O(n)，multiset_count O(|cnt|)，avoid O(m2^m·log D)（含 gcd）；阶乘空间 O(N)，avoid 额外 O(1)
- **最小调用示例**：
  ```cpp
  init(10);
  ll choose=C(10,3),perm=multiset_count({2,3});
  ll count=avoid(100,vector<ll>{2,3});
  ```
- **注意**：所有阶乘查询必须≤预处理上限，cnt 非负且总和合法；qpow 指数非负，底数需控制模乘溢出；avoid 要求 0≤n<LLONG_MAX，以免 n+1 溢出
- **结论**：适用于排列计数和排除整除条件；组合接口只覆盖小于模数的预处理范围

## 随机数与对拍.cpp

- **功能**：提供以 steady_clock 当前计数为种子的 mt19937 随机引擎
- **接口**：
  - 全局对象 `mt19937 rnd` — `rnd()` 返回 `mt19937::result_type` 的原始随机值，并推进状态
  - `rnd.seed(mt19937::result_type value)` — 标准引擎接口，可固定种子复现；源码没有区间随机函数、数据生成器或对拍入口
- **复杂度**：单次生成摊还 O(1)，引擎状态空间 O(1)（固定大小）
- **最小调用示例**：
  ```cpp
  rnd.seed(42u);
  uniform_int_distribution<int> pick(1,10);
  int x=pick(rnd); // 闭区间 [1,10]
  ```
- **注意**：闭区间分布 pick 是示例中自行创建的标准库对象，并非源码已有接口；rnd()%范围 有模偏差，时间种子默认不能稳定复现
- **结论**：可作为随机数据与算法的引擎来源；当前文件没有实现题名所述的对拍流程
