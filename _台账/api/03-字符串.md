## AC自动机.cpp

- **功能**：统计所有模式在文本中的出现次数总和，允许重叠和重复模式
- **接口**：
  - `void clear_trie()`；`int insert(const string& str)` 返回终止结点编号；根 root=1，tot 初值 1
  - `void build_fail()` 建并补全转移；`ll query(const string& txt)` 返回总匹配次数
- **复杂度**：建图 O(总模式长+26*结点数)，查询 O(|txt|)，空间 O(26N)
- **最小调用示例**：
  ```cpp
  clear_trie(); int p=insert("aa");
  build_fail();
  cout << query("aaa");
  ```
- **注意**：只接受 a..z；先插完再 build_fail，补全后不能继续插入或重复 build；空模式计数不采用通常的 |txt|+1 语义，应使用非空模式。
- **结论**：适用于多模式匹配和模式出现总次数统计；query 不返回每个模式的单独次数。
- **独立 Trie 模块**：`PrefixLCP::insert(s)` 插入非空小写串，返回已插入串的 `sum(f[j] xor j)`；`f[j]` 是选择恰 j 个串的最大 LCP。重复串计重数；每次 O(|s|)，空间 O(26*总字长)。不依赖 AC 全局数组或 fail 构建。

## KMP.cpp

- **功能**：重叠模式计数与最小整串循环节
- **接口**：
  - `void get_nxt(const string& p)` — 写 nxt[0..|p|]，nxt[0]=-1、nxt[i] 为前 i 字符最长真 border 长度
  - `int kmp(const string& s,const string& p)` 返回出现次数，须先 get_nxt(p)，空 p 返回 0；`int min_cycle(const string& p)` 自建 nxt 并返回循环节长度
- **复杂度**：预处理 / 匹配 O(|p|+|s|)，额外数组 O(N)
- **最小调用示例**：
  ```cpp
  string p="aa"; get_nxt(p);
  int cnt=kmp("aaa",p);
  cout << cnt << " " << min_cycle("abab");
  ```
- **注意**：字符串 0 起、nxt 使用前缀长度索引，需 |p|<N；min_cycle 会覆盖 nxt；空串 min_cycle 返回 0。
- **结论**：用于单模式匹配、border 和整串周期判断。

## Manacher.cpp

- **功能**：回文子串最长长度及按位置计数
- **接口**：
  - `int Manacher::build(const string& str)` 返回变换后 len_cur=2*|str|+2，结果 rr[1..len_cur] 为对应原串回文长度
  - `int longest()` 返回最长回文长度；`ll count_pal()` 返回非空回文子串出现总数，需先 build
- **复杂度**：build / longest / count_pal 均 O(n)，空间 O(n)（静态容量 2N）
- **最小调用示例**：
  ```cpp
  M.build("aba");
  int len=M.longest();
  cout << len << " " << M.count_pal();
  ```
- **注意**：buf[0] 是 %，分隔 #，尾哨兵 !；输入应避开 %/!/分隔符及 NUL，至少保证尾哨兵之外不再匹配；2*|str|+4<2N；多个对象共享 buf/rr/len_cur。
- **结论**：用于线性回文统计；不同回文内容的去重计数用 PAM。

## Z函数.cpp

- **功能**：后缀与原串 / 模式的最长公共前缀
- **接口**：
  - `void get_z(const string& str)` — z[0]=0，z[i] 为 str 与 str[i..] 的 LCP，0<=i<|str|
  - `void get_ex(const string& s,const string& t,int* ex)` — ex[0..|s|-1] 为 t 与 s[i..] 的 LCP，同时覆盖全局 z
- **复杂度**：get_z O(|str|)，get_ex O(|s|+|t|)，空间 z 数组与调用方 ex
- **最小调用示例**：
  ```cpp
  string s="ababa",t="aba"; int ex[5]={};
  get_ex(s,t,ex);
  cout << ex[0] << " " << ex[2];
  ```
- **注意**：get_ex 初始 r=0 时读取 z[0]=0；空模式按代码返回全零；ex 至少 |s| 个元素且不与 z 别名，模式长度不超过 z 容量。
- **结论**：用于前缀匹配、扩展 KMP 和字符串拼接比较。

## 后缀数组.cpp

- **功能**：建立后缀排名及相邻后缀 LCP
- **接口**：
  - `void build_sa(char* str)` — 读取 0 起 NUL 终止串，回填全局 n
  - 输出 sa[0..n-1] 为排名到起点、rk[0..n-1] 为起点到排名；height[0]=0，height[i]=LCP(sa[i-1],sa[i])
- **复杂度**：O(n log n)，空间 O(n)（静态数组 O(N)）
- **最小调用示例**：
  ```cpp
  char str[]="banana";
  build_sa(str);
  cout << sa[0] << " " << height[1];
  ```
- **注意**：所有排名和起点均 0 起；空串只设 n=0，不清旧结果；需 max(n,300)<N；内嵌 NUL 截断，字符初排按 unsigned char，后续比较只判断相等。
- **结论**：配合 height 的 RMQ 可查询任意后缀 LCP，也可统计不同子串。

## 后缀自动机SAM.cpp

- **功能**：子串状态、出现次数、不同子串数及最长公共子串
- **接口**：
  - `void sam_init()` 根 1；`void sam_extend(int c)` 实际参数为 0..25 的字母编号；`void sam_build()` 沿 link 汇总 siz
  - `ll count_diff_substr()` 返回不同非空子串数；`int longest_common(const string& t)` 返回与建图串最长公共子串长度
- **复杂度**：固定 26 字母建图 / 汇总 O(n)，不同子串统计 O(状态数)，公共子串 O(|t|)，空间 O(26N)
- **最小调用示例**：
  ```cpp
  sam_init(); for(char c:string("ababa")) sam_extend(c-'a');
  sam_build();
  cout << count_diff_substr() << " " << longest_common("baba");
  ```
- **注意**：不是传字符 ASCII；状态 1..tot，id 下标 0..tot-1；N 按至多约 2*串长开；sam_build 只能汇总一次，否则 siz 重复累加；空状态 len[0] 需保持零。
- **结论**：用于子串计数、频率分析和公共子串查询。

## 回文自动机PAM.cpp

- **功能**：按内容建立不同回文与出现次数
- **接口**：
  - `void pam_init()` 根 0（长 0）、1（长 -1）；`void pam_extend(int i)` 添加已赋值的 str[i]，原串 1 起；`void pam_build()` 汇总 siz
  - `int count_pal()` 返回不同非空回文个数；`int longest_pal()` 返回最长长度；`int get_fail(int p,int i)` 返回可扩展回文后缀状态
- **复杂度**：固定字母建图 / 汇总 O(n)，longest_pal O(状态数)，count_pal O(1)，空间 O(26N)
- **最小调用示例**：
  ```cpp
  pam_init(); str[0]='#'; string t="aba";
  for(int i=1;i<=(int)t.size();i++) { str[i]=t[i-1]; pam_extend(i); }
  pam_build(); cout << count_pal() << " " << longest_pal();
  ```
- **注意**：仅小写字母；pam_init 设置 str[0]；所有 extend 后调用一次 pam_build，之后不可继续追加或重复累加。pos[u] 保存第一次出现的右端点，可与 len[u] 还原内容。
- **结论**：用于不同回文去重、回文频率与最长回文；按位置总数与 Manacher 不同。

## 序列自动机.cpp

- **功能**：子序列成员查询和不同子序列计数
- **接口**：
  - `void build_seq(const string& t)` — 建 nxt[0..len][0..25]，实际含当前位置 i，缺失哨兵 len
  - `bool is_subseq(const string& t)` — 使用全局 s 的长度及已建 nxt；`ll count_diff_subseq()` — 使用全局 s，返回不同子序列数（含空串）
- **复杂度**：建图 O(26n)，成员查询 O(|t|)，计数 O(n)；nxt 空间 O(26N)，计数临时 O(N)
- **最小调用示例**：
  ```cpp
  s="ababa"; build_seq(s);
  bool ok=is_subseq("aaa");
  cout << ok << " " << count_diff_subseq();
  ```
- **注意**：0 下标，nxt[i] 包含 i，哨兵 len；build_seq 会同步全局 s。len<N，仅小写字母；不同子序列计数须放入 ll。
- **结论**：用于固定母串大量子序列查询和不同子序列 DP。

## 有限状态自动机DP.cpp

- **功能**：统计避开所有禁串的定长字符串数
- **接口**：
  - `AutomatonDP::void init(int s)` 字母表大小 1..26；`void insert(const string& s)`；`void build()`，根 1，状态 0 不用
  - `ll count(int n,ll mod)` — 长度 n>=0、mod>0，返回模 mod 的合法串数，必须已 build
- **复杂度**：建图 O(总模式长+S*sig)，计数 O(n*S*sig)，空间 O(S*sig)，滚动 DP O(S)
- **最小调用示例**：
  ```cpp
  AutomatonDP t; t.init(2); t.insert("aa");
  t.build();
  cout << t.count(3,1000000007);
  ```
- **注意**：顺序 init→insert→build→count；字母仅 a..a+sig-1，非法输入抛异常；build 后插入抛 logic_error，重复 build 可用；空禁串使所有长度答案为 0。
- **结论**：用于禁止模式计数与有限状态 DP；无禁串时等价 sig^n 取模。

## 字符串哈希.cpp

- **功能**：一维前缀单哈希与双模哈希
- **接口**：
  - `Hash1::void build(const string& str)`、`ull get(int l,int r)` — 单哈希，unsigned long long 自然溢出
  - `Hash2::void build(const string& str)`、`pair<ull,ull> get(int l,int r)` — 双模 1e9+7/1e9+9；l>r 分别返回 0/{0,0}
- **复杂度**：建表 O(n)，子串查询 O(1)，每对象静态空间 O(N)
- **最小调用示例**：
  ```cpp
  H1.build("ababa"); H2.build("ababa");
  auto x=H2.get(1,3),y=H2.get(3,5);
  cout << (x==y);
  ```
- **注意**：传入 string 0 起，但 get 是 1 起闭区间，1<=l<=r<=长度<N；相同哈希仍可能碰撞，比较子串要同时比较长度；大对象放静态区。
- **结论**：用于子串相等判定及配合二分的 LCP 查询。

## 最小表示法.cpp

- **功能**：寻找循环移位的最小 / 最大字典序表示
- **接口**：
  - `int min_show(const string& t)` — 最小表示起点，0 起；`int max_show(const string& t)` — 最大表示起点
  - `string min_str(const string& t)` — 返回最小循环表示字符串；空串起点为 0、结果为空串
- **复杂度**：起点 O(n)/O(1)，构造 min_str O(n) 时间及空间
- **最小调用示例**：
  ```cpp
  string t="baca";
  int p=min_show(t); string r=min_str(t);
  cout << p << " " << r;
  ```
- **注意**：返回原串 0 起下标，不是 1 起位置；只比较循环移位，不考虑反转；字符比较按 char 转 int，非 ASCII 字节顺序受 char 符号性影响。
- **结论**：用于环状字符串规范化和判断循环同构。
