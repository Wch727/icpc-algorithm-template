## 当前取舍建议

“仓库中有、本地没有”只说明能力差异，不能直接推出必须打印。以上样本支持的方向是：通用实现保留可靠版本，有限纸张更多用于适用条件、维护的信息和可迁移的组合技巧。难题不等于冷门算法题；抽样中没出现也不等于算法永远无用。

| 收录位置 | 建议 |
|---|---|
| 正文优先 | 常用 DP 与优化条件；BIT/线段树/分块/单调结构；LCA、DSU on Tree、长链剖分；最短路、连通性、匹配与费用流；KMP/Z/AC/SA/SAM；组合数、容斥、线性基、NTT；二维凸包、圆、切线、旋转卡壳、闵可夫斯基和 |
| 值得保留、按篇幅取舍 | WQS 说明、莫队变体、线段树分裂合并、Beats、同余最短路、Slope Trick、斯坦纳树；它们的价值不能只看“难不难” |
| 默认作为电子扩展候选 | 一般图带权匹配、支配树、单纯形、三维凸包、Delaunay/Voronoi、后缀树、一般图边染色、Min_25 和多项式复合等较长或专门实现；是否打印按专项训练需求判断 |
| 暂停新增 | PQ 树、Top Tree、ETT、洲阁筛。当前没有足够依据让它们优先挤占正文；这不是对全部近期赛事作出的缺席断言 |
| 合并替代实现 | Wavelet Tree 与主席树、Push–Relabel 与 Dinic、Hungarian 与 KM、Hopcroft–Karp 与朴素匹配，按实际需求选正文版本；可选性能优势不等于必须重复打印 |

不要恢复用户明确去掉的排序、普通二分、一维前缀和等基础代码。二分在题解里出现可以支持写“判定单调性/答案上下界”的提示，不能据此把普通二分模板重新放回去。
