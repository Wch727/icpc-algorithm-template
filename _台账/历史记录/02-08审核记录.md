## 正文与接口

- 纯暴力对照、测试随机数和测试辅助函数移到对应测试文件，减少打印正文的无关代码。
- 对算法所需条件补充说明：例如决策单调性的证明条件、斜率优化输入顺序、字符串字符集、节点容量、整数范围、多组数据清理。
- 修正接口说明中的旧函数名、已移走的测试函数和存图方式；KM 当前 DFS 实现按最坏 O(n⁴) 标注。
- 本轮没有统一删除所有替代实现，也没有统一改写所有数组存图。残量网络的边池和部分树上算法仍沿用原实现，之后可逐份整理。

## 验证

2026-10-02，在全部本轮代码修改完成后运行 `_台账/verify.py`，进程退出码 0：**扫描到 147 份模板、136 份测试，异常 0**。模板进行了语法和风格检查，测试进行了编译、运行及失败输出检查。验证启动时已包含部分新增文件；新增文件通过这些自动检查，不代表已完成本轮人工审核。之后仅修改说明文档。

回归用例覆盖空串/空前缀、满哈希表、重边/自环、负数、INT_MIN/INT_MAX、接近 ll 上限的模数与区间、拼图浅层 BFS 对照、几何共线及边界延长线等。修正了凸包测试生成负坐标时的无符号减法，以及骑士拼图测试中生成多个空格的问题；测试中的布尔对拍结果加入断言，避免打印失败但仍正常退出。

验证器使用每次运行唯一的可执行文件名，减少同时验证的文件冲突；断言失败、非零退出、超时及失败输出会导致验证失败。当前测试通过表示已有检查未发现错误，具体模板仍需遵守源码和 API 中的使用条件。
