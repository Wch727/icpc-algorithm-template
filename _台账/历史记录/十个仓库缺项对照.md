# 十个仓库缺项对照

> 历史快照：数量、待办和编译情况仅描述该阶段，不代表当前版本。当前状态与打印方式统一见 [维护说明](../维护说明.md)。本地题解与缓存未随仓库发布。

核对日期：2026-10-02。当次核对时正式章节 01–09 共 159 份 cpp；根目录旧练习代码不计入模板库。

本次取得下列 10 个仓库的完整递归文件树，均未被 GitHub 截断；再读取 39 个候选源码文件，核对其注释、接口与关键实现，并与本地相关实现及结论速查比较。不是对这 10 个仓库所有算法逐个进行正确性测试，也不是穷尽所有可能缺项。下表优先级是结合当前库和打印篇幅作出的取舍，不是比赛出现频率统计。

来源既有 ICPC codebook，也有可用于 ICPC 的通用竞赛算法库；不把它们都称作官方队伍模板。多个仓库可能共享同一实现，例如 bqi 的最大团注明来自 KACTL，因此仓库数量不能当成独立验证次数。

## 新确认、值得优先考虑的缺口

这些是本轮更明确的增量；有些在上轮 OI Wiki 对照中已经提到，下面细化其实际功能。先后顺序兼顾新增能力、复用现有代码和打印密度，不建议整表一次加入。

| 内容 | 本地差异及实际用途 | 建议收录方式与依据 |
|---|---|---|
| 两圆交面积、圆与多边形交面积 | 当前圆模板只有交点与公切线；多边形面积也没有圆弧部分 | 两圆交面积作为短函数；圆多边形交面积按有向边累加，不另造大型几何类。[nus 源码](https://github.com/ngthanhtrung23/ACM_Notebook_new/blob/HEAD/Geometry/circle.h)、[kactl 源码](https://github.com/kth-competitive-programming/kactl/blob/HEAD/content/geometry/CirclePolygonIntersection.h) |
| 曼哈顿 MST | 现有 Kruskal/Prim 不生成曼哈顿距离完全图的少量候选边；枚举所有点对会有平方级规模 | 方向扫描产生 O(n) 候选边，再复用 Kruskal；O(n log n)。[kactl 源码](https://github.com/kth-competitive-programming/kactl/blob/HEAD/content/geometry/ManhattanMST.h)、[ei1333 源码](https://github.com/ei1333/library/blob/HEAD/graph/mst/manhattan-mst.hpp) |
| Gomory–Hu 树（割树） | 有单对 s-t 最小割，缺用一棵树表示无向图所有点对最小割的构建过程 | 复用 Dinic，约 n−1 次最大流；查询为树路径最小边。无向容量图，不能直接套有向图。[kactl 源码](https://github.com/kth-competitive-programming/kactl/blob/HEAD/content/graph/GomoryHu.h)、[spaghetti 源码](https://github.com/spaghetti-source/algorithm/blob/HEAD/graph/gomory_hu_tree.cc) |
| 最大团 / 一般图最大独立集 | 现有 DFS 剪枝没有这类专用搜索；二分图最小点覆盖不能处理一般图 | 一份 bitset + 分支界限/着色上界实现；补图得到最大独立集。最坏仍指数级，不能承诺固定 n 必过。[kactl 源码](https://github.com/kth-competitive-programming/kactl/blob/HEAD/content/graph/MaximumClique.h)、[bcw 源码](https://github.com/chmnchiang/bcw_codebook/blob/HEAD/codes/Graph/Maximum_Clique/Maximum_Clique.cpp) |
| 任意模数卷积 | 现有 NTT 固定 998244353；普通 double FFT 对整数卷积舍入，不能直接支持任意大模数与系数 | 多模 NTT + CRT 或拆系数 FFT 二选一；必须注明变换长度、系数重构界或浮点精度界。“任意模”不是无条件任意规模。[nyaan 源码](https://github.com/NyaanNyaan/library/blob/HEAD/ntt/arbitrary-ntt.hpp)、[ei1333 源码](https://github.com/ei1333/library/blob/HEAD/math/fft/arbitrary-mod-convolution.hpp) |
| 不相交子集卷积 | 现有 SOS 是子集/超集求和；FWT 的 OR 卷积允许两个集合重叠 | 补 h[S]=Σ(T⊆S) f[T]g[S\T]；按 popcount 分层，O(k²2^k) 时间、O(k2^k) 空间。可接在 SOS 后。[nyaan 源码](https://github.com/NyaanNyaan/library/blob/HEAD/set-function/subset-convolution.hpp)、[shohag 源码](https://github.com/ShahjalalShohag/code-library/blob/HEAD/Dynamic%20Programming%20Optimizations/SOS%20convolutions.cpp) |
| 整数拆分数（五边形数递推） | 完全背包能做基本拆分计数，但没有该递推；Stirling 计数的是集合划分，问题不同 | 优先放公式和一段 O(n√n) 短代码；p(0)=1，符号 ++-- 循环，注明模数/溢出。[foreverbell 源码](https://github.com/foreverbell/acm-icpc-cheat-sheet/blob/HEAD/src/math/number-partition.cpp) |
| 稳定匹配（Gale–Shapley） | 匈牙利/KM 优化数量或总权，不保证双方偏好下没有阻塞对 | 短实现加严格偏好、完整列表等基本前提；O(n²)，说明提议方最优。[nus 源码](https://github.com/ngthanhtrung23/ACM_Notebook_new/blob/HEAD/Graph/Matching/StableMarriage.h)、[shohag 源码](https://github.com/ShahjalalShohag/code-library/blob/HEAD/Graph%20Theory/Stable%20Marriage%20Problem.cpp) |
| 矩阵求逆 / 多右端项消元 | 已有实数/模素数消元只返回单个右端项的一组解；无直接矩阵逆接口 | 扩展原高斯文件，对 [A|I] 一次消元；不对每个单位向量重跑 n 次。需区分实数精度、素数模域、奇异矩阵。[stanford 源码](https://github.com/jaehyunp/stanfordacm/blob/HEAD/code/GaussJordan.cc)、[kactl 源码](https://github.com/kth-competitive-programming/kactl/blob/HEAD/content/numerical/MatrixInverse-mod.h) |
| 圆并面积 | 现有扫描线只算轴平行矩形面积并，不能替代圆弧覆盖扫描 | 比前面的圆交面积更长，作为第二轮几何补充；处理同圆、包含和角度跨界。参考实现要求先去重同圆。[foreverbell 源码](https://github.com/foreverbell/acm-icpc-cheat-sheet/blob/HEAD/src/computational-geometry/circle-area-union.cpp) |

若只先补少量：两类圆交面积、曼哈顿 MST、割树、最大团是这轮较值得考虑的一组；任意模卷积和子集卷积按数学/状压题训练需求接着补。整数拆分和矩阵逆更适合追加到已有文件，而不是增加一整套重复基础代码。

## 不要误算成全新缺口

- Wavelet Tree：本次读取了 [bqi 源码](https://github.com/bqi343/cp-notebook/blob/HEAD/Implementations/content/data-structures/1D%20Range%20Queries%20%289.2%29/Wavelet.h)。其静态区间第 k 小用途已有主席树覆盖；可作为空间/常数与接口选择，暂不重复打印。
- Hopcroft–Karp、Push–Relabel：已有匈牙利/Dinic，主要是性能和实现选择；不与“缺稳定匹配”混为一谈。
- O(n³) Hungarian：[kactl 源码](https://github.com/kth-competitive-programming/kactl/blob/HEAD/content/graph/WeightedMatching.h) 明确是二分图带权匹配。它值得替换现有较慢的 KM 实现，但属于升级，不是一般图带权匹配的证据。
- 换根 DP：现有树形 DP/结论速查已有相关例子；泛型 rerooting 是组织方式，不能仅因没这个英文文件名就报完全缺失。
- 01 Trie、左偏树、AHU、BM、floor_sum、Simpson：上轮已补；WQS 和 Burnside 的说明也已加入结论速查。
- 排序、普通二分、一维前缀和等用户明确删除的基础项，不重新添加。

## 本轮产物和范围

只新增这份对照报告，未改正式算法 cpp、接口表或 PDF 生成器。外部源码保存在忽略目录 `bin/repo-audit/`，仅供本轮检查，不加入打印目录。

后续若采用外部代码，仍须独立实现/整理、保留适用条件并进行测试；不能用仓库的“tested”注释代替本地验证。也应按具体文件的许可处理引用，例如读到的 KACTL 最大团标记 GPL3+，并非 KACTL 中所有文件都使用同一许可。
