# 模板验证约定

2026-10-02。优先手造边界样例，配少量独立对照；随机次数由风险决定，不要求每个模板跑几千轮。

## 怎么造样例

| 类别 | 优先检查 |
|---|---|
| 图论 | 单点、孤立点、森林、重边、自环、同权、零权/负权（仅适用算法）、无解；有向与无向分别检查 |
| 区间数据结构 | 单点区间、端点、整段、嵌套/交叠更新；先加后乘与先乘后加；重复查询；多次初始化 |
| 数学 | 0/1、负参数（若支持）、奇异矩阵、不可逆元素、模数边界、接近类型上限 |
| 字符串 | 空串（若支持）、单字符、全相同、周期串、重复模式、长短串相互包含 |
| 几何 | 共线、重合、相切、平行、零面积、方向相反、精度边界；仅验证接口承诺的输入 |

手造样例应写明预期结果和要覆盖的条件。复杂算法用少量小规模随机输入补漏，优先穷举可核对的规模，失败时保存输入。验证更新顺序时用非交换操作；避免参考答案照抄同一实现。

## Python 参考答案

- 标准库即可处理不少小规模对照：`itertools` 枚举匹配/子集，`fractions.Fraction` 精确有理数，Python 整数核对溢出边界。
- [SciPy 的图算法接口](https://docs.scipy.org/doc/scipy/reference/sparse.csgraph.html) 提供最短路、最小生成树、最大流、二分图匹配。
- [SymPy 矩阵接口](https://docs.sympy.org/latest/modules/matrices/matrices.html) 可核对精确行列式、秩、逆矩阵和方程求解。模意义消元应明确运算域，不能直接拿普通有理数结果替代。

使用库前先统一接口语义。重边求最短路时应取最小权，最大流时应按容量合并；稀疏矩阵的重复项可能自动求和。零权边与无边须区分；浮点答案使用合适误差，精确整数结果不能仅靠浮点核对。

速度方面，C++ 测试驱动一次编译、一次运行，在进程内批量处理样例；Python 参考库也批量调用，不为每个样例启动新进程。现成库主要减少参考算法的编写工作，能否加速由实际运行决定。

现有有效测试保留；后续维护不增加重复验证。PDF 正文只收录模板和说明。
