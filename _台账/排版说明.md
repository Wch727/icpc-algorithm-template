# 手册排版说明

当前文档为根目录的 [ICPC算法手册.tex](../ICPC算法手册.tex)，默认 A4 纵向双栏。代码 7.8 pt、行距 8.8 pt，正文 8.3 pt；黑白，无代码边框、底色和逐行编号，适合双面打印。

## 内容规则

- 默认收录现有 199 份代码模板、STL 速查表及模型判据、常用结论；不收录测试、个人逐题台账和下载题解。
- STL 以两列操作表格排版；共有操作合并，保留不重复的写法、复杂度与边界，不生成演示 cpp。
- 第一章按“说明—代码—说明—代码”排版：用途、条件、复杂度和模块说明从代码注释中提取为正文；语句附近的注释继续留在代码内。BigInt 按公共部分和各运算区分段，所有片段仍属于同一个 struct。
- 此排版重排只影响手册；cpp 中的说明仍便于复制时查阅，算法实现与测试入口保持完整。后续章节逐章整理，暂不机械拆开全部实现。
- 实现不截断，不按行数上限剪掉函数。只省略重复的 bits 头文件、`using namespace std` 和 `ll` 公共定义，并收紧空行。
- 容量、常量、其他类型别名和依赖声明保留；有外部算法依赖的条目须配合所注明的对应实现使用。
- 高维差分保留三维代码，一般 D 维建差分、容斥还原、逐维递推、角点修改以数学公式排在代码旁。
- 期望自环、Bell 数、范德蒙德、子集贡献、块 XOR、凸区域外扩、WQS、Burnside 等已排成公式或紧凑说明。
- 目录带页码与 PDF 书签；每个模板独立使用，重复的全局名不表示能整本拼接编译。

## 生成与调整

```powershell
python _台账/生成LaTeX.py
python _台账/生成PDF.py
```

[打印配置.json](打印配置.json) 是唯一选材配置：

- `code_font_pt` / `code_leading_pt`：代码字号 / 行距。
- `include_notes`：是否收录结论部分。
- `exclude`：不打印的模板相对路径数组。省略只影响打印，不删除电子库代码；拼错路径会报错。

修改算法内容应改对应 cpp，STL 操作表改对应 Markdown，再重新生成。持续修改排版应改 `生成LaTeX.py`，因为重新生成会覆盖 tex；在编辑器临时调整 tex 后，可以先直接编译当前文件查看效果。

`生成PDF.py` 不负责安装软件；优先使用环境变量 `XELATEX` 指定的编译器，其次查 PATH 和本机已有 TeX Live。使用无 shell escape 的 XeLaTeX，并重复编译至目录稳定。输出位于 `output/pdf/`，临时文件位于 `build/latex/`。

内置编辑器如报 `Unable to find standard directories for platform`，编译器尚未开始检查文档；不能通过删改算法解决。保留源文件与当前编辑器，本机已有 TeX Live 可以生成同一源文件的 PDF。
