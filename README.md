# ICPC 个人算法库

从 `D:\code`（洛谷题解、CSES、比赛代码、ICPC 2025 南京站）和桌面的 AtCoder / Codeforces 文件夹提取出来的个人算法模板库。

- **一个算法两个文件**：`0X-*/*.cpp` 是**纯模板**（只有实现和注释，没有 `main`），`测试/0X-*/*_test.cpp` 是**测试与对拍**（`#include` 模板本体再跑暴力对拍）
- 147 个模板全部通过：模板能单独编译 + 测试编译运行无 `FAIL`
- 可打印 PDF：`python _台账/生成PDF.py`（模板正文 + API 说明 + 结论，自动排除测试代码）

| 想干什么 | 看这里 |
|---|---|
| 找某个算法在哪个文件 | [索引.md](索引.md)（自动生成：模板 + 说明 + 你相关的题） |

## 维护约定

1. 新增模板：**纯模板**放 `0X-*`（无 `main`），**测试**放 `测试/0X-*`（`#include` 模板 + 对拍），遵守 [风格说明.md](风格说明.md)。
2. 改完跑 `python _台账/verify.py`（模板语法检查 + 测试编译运行 + 输出无 FAIL），要求**异常 0**。
3. 生成打印稿：`python _台账/生成PDF.py`（两份 PDF 在 `build/`）。
4. 本机两个坑：
   - 写完 `.cpp` **等 1~2 秒再编译**，否则 g++ 可能读到旧内容（"改了不生效"的假 bug）。
   - exe 输出名**不要用中文**（g++ 在 Windows 下会按 GBK 解释成乱码路径）。

> 说明：库里不少进阶模板（SAM、LCT、替罪羊树、半平面交、多项式全家桶等）在台账里没有直接对应的题，是按 ICPC 常规补齐的；[索引.md](索引.md) 里这些文件的「相关题目」列为空，属正常。
