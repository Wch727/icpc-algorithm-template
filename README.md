# ICPC 个人算法库

从 `D:\code`（luogu 700+ 份题解、CSES、AtCoder/Codeforces 比赛代码、ICPC 2025 南京站等）里提取出来的个人算法模板库。
**一个算法一个文件**，每个文件都能独立编译运行，赛场上直接复制需要的部分即可。

- 写作规范见 [风格说明.md](风格说明.md)（从你实际代码里提取的硬性风格约定）
- 全量自检：`pwsh -File .\自检.ps1`（逐个编译 + 运行 + 风格检查），也可 `pwsh -File .\自检.ps1 04-图论` 只查一个目录
- 编译器：`C:\mingw64\bin\g++.exe -std=c++2b -O2 -Wall`，或直接用 VS Code 任务 `C/C++: g++.exe 生成活动文件`

## 目录结构

```
01-基础与技巧/     二分、三分、前缀和、单调栈/队列、排序、离散化、位运算、高精度
02-数据结构/       并查集、树状数组、线段树系列、分块、ODT、ST表、Trie、哈希表、堆、BST、Treap、链表、树剖、主席树、莫队
03-字符串/         字符串哈希、KMP、Manacher、Z函数、AC自动机、后缀数组
04-图论/           存图、最短路四种、拓扑、MST、LCA、二分图、Tarjan、匈牙利、Dinic
05-数学/           快速幂、矩阵快速幂、线性筛、exgcd、逆元、组合数与Lucas、高斯消元、CRT、博弈论、线性基、PollardRho、NTT
06-动态规划/       背包系列、LIS、LCS、区间DP、状压DP、树形DP、单调队列优化、数位DP
07-搜索/           DFS剪枝、BFS最短路、迭代加深与IDA*、A*与K短路
08-计算几何/       向量基础、凸包、旋转卡壳与多边形面积
09-其他/           随机数与对拍、交互题模板、卡常技巧
```

> 说明：标注 **(补)** 的条目在你 `D:\code` 里没有对应代码，是按同一风格补齐的 ICPC 常规必备项，可以直接删掉不影响别的文件。
> 其余每个文件都能在你的 `D:\code` 里找到原始出处（见下表「原题/出处」列）。

## 使用方式

1. 赛场上：打开对应文件，把模板部分（`struct` / 函数 / 全局数组）复制到自己的 `main` 前面，按题目重写 `main`。
2. 每个文件的 `main()` 里都写了自测/对拍，可以直接运行确认模板没被改坏。
3. 新增模板请遵守 [风格说明.md](风格说明.md)，然后跑一次 `.\自检.ps1`。
