## 使用

`01-*` 至 `09-*` 中的 `.cpp` 是纯模板，没有 `main`。复制所需实现到解题代码，按注释设置容量、下标和参数；文件内的多个模块可按需摘用。常规图模板使用 vector 邻接表。

使用 GCC，部分实现依赖 `bits/stdc++.h` 和 `__int128`。当前验证参数为 `-std=c++2b`。

## 验证

`测试/` 中共有 **194 份测试文件**，通过相对路径包含模板本体。以手造边界样例和独立对照为主，辅以随机对拍。

```powershell
# 全库检查 / 仅检查一个章节
python _台账/verify.py
python _台账/verify.py 04-图论

# 重新生成索引
node _台账/生成索引.mjs
```

验证脚本默认使用本机 MinGW 路径，换环境时调整其中的编译器配置。维护规范见 [代码风格](风格说明.md) 与 [测试约定](_台账/测试约定.md)。
