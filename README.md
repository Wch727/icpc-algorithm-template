## 使用
| 39 | 39 |
1. 在索引中找到算法，先确认适用条件、复杂度与依赖。
2. 将所需实现复制到自己的解题代码，设置容量、模数、下标和初始化参数。
3. 参考 `测试/` 下的对应文件了解调用方式，并针对题目边界验证。
| 39 | 39 |
`01-*`至`09-*`中的`.cpp`是纯模板，没有`main`；同一文件内的多个模块可按需摘用。各模板独立使用，全局变量与类型名可能重复，不适合将整个目录直接拼接编译。输入和主要状态优先放全局；独立数据结构实例、矩阵/多项式运算及几何对象保留必要的对象参数。图统一使用vector邻接表；需要区分重边时保存边编号，残量网络使用vector边表配合邻接表。
| 39 | 39 |
使用 `g++` 编译，部分实现依赖 `bits/stdc++.h` 和 `__int128`。当前验证参数为 `-std=c++2b`。

## 验证
| 39 | 39 |
`测试/` 中共有 **191 个 C++ 测试入口**，另有辅助头文件。测试直接引用模板本体，包含边界样例、独立对照和随机对拍；维护以手造样例和少量对照为主。
| 39 | 39 |
```powershell
# 全库检查 / 仅检查一个章节
python _台账/verify.py
python _台账/verify.py 04-图论
| 39 | 39 |
# 指定编译器与并行任务数
python _台账/verify.py 04-图论 --compiler g++ --jobs 4
| 39 | 39 |
# 重新生成索引
node _台账/生成索引.mjs
```
| 39 | 39 |
验证脚本按 `--compiler`、环境变量 `CXX`、PATH 中的 `g++` 顺序查找编译器；Windows 还兼容 `C:\mingw64\bin\g++.exe`。编译器参数使用 `-std=c++2b`，需支持该参数；`CXX` 只填可执行文件路径，不附带参数。Windows 测试会设置 64 MiB 栈，其他系统使用系统默认栈限制，递归较深时需自行调整。维护规范见 [代码风格](风格说明.md) 与 [测试约定](_台账/测试约定.md)。
