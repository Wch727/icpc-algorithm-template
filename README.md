# ICPC 算法模板库

面向 ICPC / CCPC 训练与比赛的 C++ 算法模板库，提供 **199 份代码模板、STL 速查表和常用结论**，配套可打印的 A4 双栏 LaTeX 手册。

模板附中文说明，涵盖适用条件、复杂度、易错边界和关键公式。代码按算法分类，测试与实现分开；可以摘取单个模块，也可以按需要选择手册的打印内容。

查找算法从 [模板索引](索引.md) 开始；查询调用方式看 [接口说明](_台账/api/README.md)；准备纸质手册看 [排版说明](_台账/排版说明.md)。

## 使用

1. 在索引中找到算法，先确认适用条件、复杂度与依赖。
2. 将所需实现复制到自己的解题代码，设置容量、模数、下标和初始化参数。
3. 参考 `测试/` 下的对应文件了解调用方式，并针对题目边界验证。

`01-*` 至 `09-*` 中的 `.cpp` 是纯模板，没有 `main`；同一文件内的多个模块可按需摘用。各模板独立使用，全局变量与类型名可能重复，不适合将整个目录直接拼接编译。常规图模板使用 vector 邻接表。

使用 GCC，部分实现依赖 `bits/stdc++.h` 和 `__int128`。当前验证参数为 `-std=c++2b`。

## 验证

`测试/` 中共有 **196 个测试入口**，另有辅助头文件；包括引用模板本体的C++测试和题解公式的独立Python对照。包含边界样例、独立对照和随机对拍；后续维护以手造样例和少量对照为主。

```powershell
# 全库检查 / 仅检查一个章节
python _台账/verify.py
python _台账/verify.py 04-图论

# 指定编译器与并行任务数
python _台账/verify.py 04-图论 --compiler g++ --jobs 4

# 重新生成索引
node _台账/生成索引.mjs
```

验证脚本按 `--compiler`、环境变量 `CXX`、PATH 中的 `g++` 顺序查找 GCC；Windows 还兼容 `C:\mingw64\bin\g++.exe`。编译器参数使用 `-std=c++2b`，需支持该参数；`CXX` 只填可执行文件路径，不附带参数。Windows 测试会设置 64 MiB 栈，其他系统使用系统默认栈限制，递归较深时需自行调整。维护规范见 [代码风格](风格说明.md) 与 [测试约定](_台账/测试约定.md)。
